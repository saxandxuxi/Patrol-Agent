# 项目原则：提示词与事实源一致性

> 本文件与 `项目原则-禁止正则与关键词硬匹配.md`、`项目原则-AI晋级考试与用户裁决.md`
> 同时生效。修改提示词、QuerySpec、能力配置、MDL 投影、SQL 审计或修复票据前，
> 必须先阅读本文件。

## 一、唯一事实源

1. 一个机器可读的语义事实只能有一个 owner。字段标签、枚举编码与展示值、表中文名、
   实体成员、指标公式、关系拓扑、SQL 形状和业务谓词都必须能指认唯一来源。
2. 别名不是第二份事实。同义说法只能登记为 alias、候选证据或引用键，不能复制
   code map、公式、JOIN 或查询范围。
3. 生成物不是人工事实源。`metadata.yml`、`target/mdl.json`、缓存和运行期模板必须
   由 owner 生成或投影，禁止手工维护后反向冒充来源。
4. 迁移某个事实时必须在同一变更中删除旧位置和旧读取分支，禁止保留“兼容期”双写。
5. 同一事实在运行时来源中冲突时，必须在构建 LLM 上下文之前返回结构化冲突证据；
   不能按文件顺序、加载顺序或模型偏好静默选边。

## 二、提示词一致性

1. 提示词之间、同一提示词内部不得存在互相排斥的规则。
2. QuerySpec 的公开视图、TopN、时间窗口、关系存在性、主体证据和依赖协议由共享投影
   注入；提示词只说明如何消费，不手抄第二份清单。
3. 审计提示词只负责发现问题、引用共享事实并输出结构化证据；不得复制 Planner 的
   业务规则，也不得通过 `set` 自行扩大修复权限。
4. `planning.md` 只描述旧 OrchestratorPlan。`{{key}}`、`needs`、`produces` 不是
   QuerySpec 语法；QuerySpec 链式依赖只接受 `depends_on` 加结构化 `inputs`。
5. 未识别的 action、字段、视图、依赖或事实必须失败关闭并生成可行动证据，不能静默
   降级成查询。

## 三、MDL 与业务能力

1. `wren_projects/` 的 MDL 拥有模型、真实列、计算列、关系拓扑、通用 cube measure
   和物理方言展开所需的结构事实。
2. `resources/capabilities/` 拥有巡检业务标签、枚举、指标口径、派生公式、查询形状、
   能力缺口和口语候选证据。
3. MDL 与 `resources/capabilities/` 是平等、互补的事实源，不存在全局优先级。两边
   同时进入 Planner、合同、审计和 MDL-SQL 生成上下文；冲突时失败关闭。
4. 通用 measure 已由 MDL 表达时，`metrics.yaml` 只能通过
   `source.kind=mdl_cube` 引用；巡检特有指标由 `metrics.yaml` 或
   `derived_metrics.yaml` 拥有，MDL 不得用第二个公式重复定义。
5. 关系只从 MDL 读取；`subjects.yaml` 不得重新出现 JOIN 字段。实际字段引用必须
   能在 MDL 模型或列上解析。
6. 普通比例、密度、差值、占比和增长率由 `CalculationRequest` 组合，不能为每种
   对象或问法复制一个固定公式。QuerySpec 仍是用户范围和查询形状的权威。

## 四、执行边界

1. Wren 可以复用 MDL 模型、真实列、计算列、关系子图、`dry-plan` 和物理 SQL 展开；
   但不能绕过 QuerySpec、冻结合同、统一 SQL 审计和用户范围校验。
2. 只有合法合同下确定性编译器明确返回 `compiler_not_covered`，才允许调用一次
   LLM MDL-SQL 兜底。合同冲突、安全拒绝、范围失败、确定性 SQL 审计失败和
   `dry-plan` 失败都必须回到 QuerySpec 修复或结构化失败。
3. 修复最多两轮。相同证据或相同补丁立即停止；修复不得改变用户原问题、主体、时间、
   路线、病害、设备、任务或其他范围。

## 五、验收门禁

每次涉及提示词、能力注册表、QuerySpec、SQL 编译或结果验收的修改，提交前必须：

1. 扫描是否存在提示词规则与共享事实冲突。
2. 扫描是否存在同一事实在 YAML、Python、提示词或生成物中的第二份副本。
3. 扫描是否存在一个文件同时承担多个无关职责，或一个事实被多个消费者各自解释。
4. 运行字段、枚举、指标、关系、提示词和冲突门禁测试。
5. 运行查询全量测试；涉及前端时运行前端构建；运行 `git diff --check`。
6. 检查 `resources/README.md` 的职责债务，删除已经解决的条目，禁止把债务清单当
   永久例外。

## 六、当前整改边界

本原则适用于本轮及后续的提示词单一事实源、可组合指标、MDL/resources 互补、
QuerySpec 修复和工作台调整。任何新增特例都必须先证明它是共享事实或共享契约；
题目 ID、固定问句、关键词和正则不能成为例外。
