# 冷门表参数化预置模板扩充（给 codex）

## 一、目的
现有 preset_queries.json 的 36 条模板几乎全围着 ai_problem（病害）+ routes（路线）。业务问题清单里"资产/设备任务/管养片区/长时间变化"四类，落到没数据的表（ai_asset_main、ai_distance_capture、ai_work_order、maintenance_work_order、maintenance_road_work_record、maintenance_project、project_manage_project_main、bridges/tunnels/slope 明细）时没有模板，只能走 Wren。现在把这些表先建成参数化模板，表一有数据就能直接查，不用每次走大模型。

格式严格照现有 preset_queries.json（id/category/title/question/params/sql/scope/match）。参数优先复用已有：route_id、month、damage_type、up_or_down、top_n。

## 二、新增参数（加到 params 段）
- asset_type：来源 asset_types（ai_asset_base.asset_type 去重）
- patrol_task：来源 patrol_tasks（ai_maintain_patrol.task_number 去重）
- device_code：来源 device_codes（ai_problem.device_code 去重）
- date_from / date_to：自由日期（采集时间区间）

## 三、新增模板清单

### A. 资产维度（ai_asset_main + ai_asset_base）
1. **asset_type_count**｜某类资产有多少条巡查记录
   SQL: `SELECT b.asset_type AS 资产类型, COUNT(*) AS 记录数, MAX(a.collection_time) AS 最近巡检时间 FROM ai_asset_main a JOIN ai_asset_base b ON a.asset_type_id = b.id WHERE a.del_flag=0 AND b.asset_type='{asset_type}' GROUP BY b.asset_type`
   match: shape=[count,distribution], subject=[asset], slots=[asset_type]

2. **asset_recent_records**｜某类资产最近几次巡检记录
   params=[asset_type, top_n]
   SQL: `SELECT a.problem_number AS 记录编号, a.collection_time AS 巡检时间, a.area AS 面积, a.problem_url AS 图片 FROM ai_asset_main a JOIN ai_asset_base b ON a.asset_type_id=b.id WHERE a.del_flag=0 AND b.asset_type='{asset_type}' ORDER BY a.collection_time DESC LIMIT {top_n}`

### B. 巡检任务/设备（ai_maintain_patrol）
3. **patrol_month_list**｜某月所有巡检任务清单
   params=[month]
   SQL: `SELECT t.task_number AS 任务编号, t.patrol_name AS 任务名称, t.start_time AS 开始时间, t.end_time AS 结束时间, COUNT(p.id) AS 检出病害数 FROM ai_maintain_patrol t LEFT JOIN ai_problem p ON p.patrol_id=t.id AND p.del_flag=0 WHERE t.del_flag=0 AND DATE_FORMAT(t.start_time,'%Y-%m')='{month}' GROUP BY t.id ORDER BY t.start_time DESC`
   match: shape=[list,distribution], subject=[patrol], slots=[time_range]

4. **patrol_task_detail**｜某次巡检的起止桩号与里程
   params=[patrol_task]
   SQL: `SELECT t.task_number, t.patrol_name, r.short_name AS 路线, t.start_num AS 起点, t.end_num AS 终点, t.start_time, t.end_time FROM ai_maintain_patrol t LEFT JOIN basic_facilities_routes r ON t.routes_id=r.id WHERE t.del_flag=0 AND t.task_number='{patrol_task}'`

5. **device_month_tasks**｜某台设备某月巡检了几次
   params=[device_code, month]
   SQL: `SELECT t.device_code AS 设备号, COUNT(DISTINCT t.id) AS 巡检次数 FROM ai_maintain_patrol t WHERE t.del_flag=0 AND t.device_code='{device_code}' AND DATE_FORMAT(t.start_time,'%Y-%m')='{month}' GROUP BY t.device_code`

### C. 工单/管养（ai_work_order + ai_problem）
6. **work_order_status_dist**｜工单按状态分布
   SQL: `SELECT w.order_status AS 工单状态, COUNT(*) AS 工单数 FROM ai_work_order w WHERE w.del_flag=0 GROUP BY w.order_status ORDER BY 工单数 DESC`

7. **pending_disease_list**｜待转工单病害明细（桩号/类型/采集时间）
   params=[route_id]
   SQL: `SELECT p.problem_number AS 病害编号, r.short_name AS 路线, p.pile_number AS 桩号, b.problem_type AS 病害类型, p.collection_time AS 采集时间, p.area AS 面积 FROM ai_problem p JOIN basic_facilities_routes r ON p.routes_id=r.id LEFT JOIN ai_problem_base b ON p.damage_type=b.problem_code WHERE p.del_flag=0 AND p.problem_status='0' AND p.routes_id='{route_id}' ORDER BY p.collection_time DESC LIMIT 500`
   scope: problem_status='0'=待转工单

8. **recovered_vs_ignored**｜已恢复 vs 已忽略病害占比
   SQL: `SELECT CASE p.operate_type WHEN '3' THEN '病害恢复' WHEN '15' THEN '忽略病害' WHEN '10' THEN '已转工单' ELSE p.operate_type END AS 处置, COUNT(*) AS 处数 FROM ai_problem p WHERE p.del_flag=0 AND p.operate_type IN ('3','10','15') GROUP BY 处置`

### D. 养护作业与项目（maintenance_* / project_*）
9. **road_work_month**｜某条路某月日常养护作业记录
   params=[route_id, month]
   SQL: `SELECT w.work_date AS 作业日期, w.work_type AS 作业类型, w.work_content AS 作业内容, w.worker AS 作业单位 FROM maintenance_road_work_record w WHERE w.del_flag=0 AND DATE_FORMAT(w.work_date,'%Y-%m')='{month}' AND w.routes_id='{route_id}' ORDER BY w.work_date DESC LIMIT 500`

10. **maintenance_project_list**｜养护项目台账
    SQL: `SELECT p.project_name AS 项目名称, p.project_type AS 项目类型, p.start_date AS 开工, p.end_date AS 竣工, p.budget AS 预算 FROM maintenance_project p WHERE p.del_flag=0 ORDER BY p.start_date DESC LIMIT 200`

11. **project_main_list**｜工程项目台账
    SQL: `SELECT m.project_name, m.project_type, m.status, m.budget, m.start_date, m.end_date FROM project_manage_project_main m WHERE m.del_flag=0 ORDER BY m.start_date DESC LIMIT 200`

### E. 构造物明细（替换现在只有 count 的桥/隧/边坡；列名已连库对齐真实结构）

#### 桥梁 basic_facilities_bridges（真实列：name/code/routes_id/middle_num 中心桩号/tech_level 技术等级/route_type 路线类型/span_category 跨径分类/crossing_type 跨越地物/crossing_name/maintenance_dept）
12. **bridge_detail_list**｜某条路的桥梁明细
    params=[route_id]
    SQL: `SELECT b.name AS 桥梁名称, b.code AS 编号, b.middle_num AS 中心桩号, CASE b.span_category WHEN '1' THEN '特大桥' WHEN '2' THEN '大桥' WHEN '3' THEN '中桥' WHEN '4' THEN '小桥' ELSE b.span_category END AS 跨径分类, b.tech_level AS 技术等级, b.crossing_name AS 跨越地物, b.maintenance_dept AS 养护单位 FROM basic_facilities_bridges b WHERE b.del_flag=0 AND b.routes_id='{route_id}' ORDER BY b.middle_num LIMIT 200`

12b. **bridge_span_dist**｜全库桥梁按跨径分类分布
    SQL: `SELECT CASE b.span_category WHEN '1' THEN '特大桥' WHEN '2' THEN '大桥' WHEN '3' THEN '中桥' WHEN '4' THEN '小桥' ELSE COALESCE(b.span_category,'未填') END AS 跨径分类, COUNT(*) AS 座数 FROM basic_facilities_bridges b WHERE b.del_flag=0 GROUP BY 跨径分类 ORDER BY 座数 DESC`

12c. **bridge_tech_level_dist**｜桥梁按技术等级分布
    SQL: `SELECT CASE b.tech_level WHEN '1' THEN '一级公路' WHEN '2' THEN '二级公路' WHEN '3' THEN '三级公路' WHEN '4' THEN '四级公路' WHEN '5' THEN '等外公路' ELSE COALESCE(b.tech_level,'未填') END AS 技术等级, COUNT(*) AS 座数 FROM basic_facilities_bridges b WHERE b.del_flag=0 GROUP BY 技术等级`

12d. **bridge_crossing_dist**｜桥梁按跨越地物类型分布
    SQL: `SELECT CASE b.crossing_type WHEN '1' THEN '河流' WHEN '2' THEN '跨海' WHEN '3' THEN '沟壑' WHEN '5' THEN '道路' WHEN '6' THEN '铁路' WHEN '7' THEN '水渠' ELSE COALESCE(b.crossing_type,'其他') END AS 跨越地物, COUNT(*) AS 座数 FROM basic_facilities_bridges b WHERE b.del_flag=0 GROUP BY 跨越地物 ORDER BY 座数 DESC`

#### 隧道 basic_facilities_tunnels（真实列：name/asset_code/belong_route_id/stake_start_num/center/end_num/tunnel_length 长度/tunnel_clear_width 净宽/tunnel_clear_height 净高/tunnel_type 分类/ventilate_mode 通风/lane_count/technical_assessment_grade 技术评定/civil_construction_evaluate_grade 土建评定/disease_description 病害描述/is_monitoring_device/is_lighting/manage_dept）
13. **tunnel_detail_list**｜某条路的隧道明细
    params=[route_id]
    SQL: `SELECT t.name AS 隧道名称, t.asset_code AS 编码, t.stake_start_num AS 起点, t.stake_end_num AS 终点, t.tunnel_length AS 长度_米, t.tunnel_clear_width AS 净宽, t.tunnel_clear_height AS 净高, t.lane_count AS 车道数, CASE t.tunnel_type WHEN '0' THEN '特长隧道' WHEN '1' THEN '长隧道' WHEN '2' THEN '中隧道' WHEN '3' THEN '短隧道' ELSE t.tunnel_type END AS 隧道分类, CASE t.ventilate_mode WHEN '0' THEN '局部排风' WHEN '1' THEN '局部送风' WHEN '2' THEN '全面通风' ELSE t.ventilate_mode END AS 通风方式, CASE t.technical_assessment_grade WHEN '1' THEN '一类' WHEN '2' THEN '二类' WHEN '3' THEN '三类' WHEN '4' THEN '四类' WHEN '5' THEN '五类' WHEN '9' THEN '未评定' ELSE t.technical_assessment_grade END AS 技术评定 FROM basic_facilities_tunnels t WHERE t.del_flag=0 AND t.belong_route_id='{route_id}' ORDER BY t.stake_start_num LIMIT 200`

13b. **tunnel_type_dist**｜全库隧道按分类（特长/长/中/短）分布
    SQL: `SELECT CASE t.tunnel_type WHEN '0' THEN '特长隧道' WHEN '1' THEN '长隧道' WHEN '2' THEN '中隧道' WHEN '3' THEN '短隧道' ELSE COALESCE(t.tunnel_type,'未填') END AS 隧道分类, COUNT(*) AS 座数, ROUND(SUM(t.tunnel_length),1) AS 总长_米 FROM basic_facilities_tunnels t WHERE t.del_flag=0 GROUP BY 隧道分类 ORDER BY 座数 DESC`

13c. **tunnel_grade_dist**｜隧道技术评定等级分布
    SQL: `SELECT CASE t.technical_assessment_grade WHEN '1' THEN '一类' WHEN '2' THEN '二类' WHEN '3' THEN '三类' WHEN '4' THEN '四类' WHEN '5' THEN '五类' WHEN '9' THEN '未评定' ELSE COALESCE(t.technical_assessment_grade,'未填') END AS 技术评定, COUNT(*) AS 座数 FROM basic_facilities_tunnels t WHERE t.del_flag=0 GROUP BY 技术评定 ORDER BY 技术评定`

13d. **tunnel_longest**｜最长/净宽最大的隧道 Top N
    params=[top_n]
    SQL: `SELECT t.name AS 隧道名称, t.tunnel_length AS 长度_米, t.tunnel_clear_width AS 净宽, t.tunnel_clear_height AS 净高 FROM basic_facilities_tunnels t WHERE t.del_flag=0 ORDER BY t.tunnel_length DESC LIMIT {top_n}`

13e. **tunnel_bad_disease**｜有病害描述/评定为差等的隧道
    SQL: `SELECT t.name AS 隧道名称, t.disease_description AS 病害描述, t.technical_assessment_grade AS 技术评定, t.civil_construction_evaluate_grade AS 土建评定 FROM basic_facilities_tunnels t WHERE t.del_flag=0 AND (t.disease_description IS NOT NULL AND t.disease_description<>'')`

#### 边坡 basic_facilities_slope（真实列：name/code/routes_id/height/length/start_num/end_num/nature_type 性质/slope_type 类型/protection_project 防护工程/build_year/is_vegetated）
14. **slope_detail_list**｜某条路的边坡明细
    params=[route_id]
    SQL: `SELECT s.name AS 边坡名称, s.start_num AS 起点桩号, s.end_num AS 止点桩号, s.height AS 高度_米, s.length AS 长度_米, CASE s.nature_type WHEN '1' THEN '路堤' WHEN '2' THEN '路堑' ELSE s.nature_type END AS 性质, CASE s.slope_type WHEN '1' THEN '岩质' WHEN '2' THEN '土质' WHEN '3' THEN '土石混合' ELSE s.slope_type END AS 边坡类型, CASE s.protection_project WHEN '1' THEN '植物防护' WHEN '2' THEN '骨架防护' WHEN '3' THEN '挂网喷浆' WHEN '4' THEN '片石护坡' WHEN '5' THEN '护面墙' WHEN '7' THEN '无' ELSE s.protection_project END AS 防护工程, s.build_year AS 修建年度 FROM basic_facilities_slope s WHERE s.del_flag=0 AND s.routes_id='{route_id}' ORDER BY s.start_num LIMIT 200`

14b. **slope_type_dist**｜全库边坡按岩质/土质分布
    SQL: `SELECT CASE s.slope_type WHEN '1' THEN '岩质边坡' WHEN '2' THEN '土质边坡' WHEN '3' THEN '土石混合' ELSE COALESCE(s.slope_type,'未填') END AS 边坡类型, COUNT(*) AS 处数, ROUND(SUM(s.height),1) AS 总高度_米 FROM basic_facilities_slope s WHERE s.del_flag=0 GROUP BY 边坡类型 ORDER BY 处数 DESC`

14c. **slope_protection_dist**｜边坡按防护工程类型分布
    SQL: `SELECT CASE s.protection_project WHEN '1' THEN '植物防护' WHEN '2' THEN '骨架防护' WHEN '3' THEN '挂网喷浆' WHEN '4' THEN '片石护坡' WHEN '5' THEN '护面墙' WHEN '7' THEN '无' ELSE COALESCE(s.protection_project,'其他') END AS 防护工程, COUNT(*) AS 处数 FROM basic_facilities_slope s WHERE s.del_flag=0 GROUP BY 防护工程 ORDER BY 处数 DESC`

14d. **slope_tallest**｜最高/最长的边坡 Top N

### G. 统计/对比/密度/分档类（结合规划模型认的 shape：distribution/trend/top/comparison/bucket_compare）
15. **route_disease_density_compare**｜各路线病害密度横向对比（处/公里，替换已有 route_density_rank 的密度算法统一）
    SQL: 见已有 route_density_rank，补每公里面积、单位面积密度。

15b. **route_disease_area_compare**｜各路线病害总数 vs 总面积 vs 平均面积对比（"是路长所以多还是密度高"）
    SQL: `SELECT r.short_name AS 路线, COUNT(*) AS 处数, ROUND(SUM(p.area),1) AS 总面积, ROUND(AVG(p.area),3) AS 平均面积 FROM ai_problem p JOIN basic_facilities_routes r ON p.routes_id=r.id WHERE p.del_flag=0 AND r.del_flag=0 GROUP BY r.id, r.short_name ORDER BY 处数 DESC`
    match: shape=[comparison,distribution], subject=[route], metrics=[count,total_area,avg_area]

15c. **route_direction_density**｜某条路上行/下行病害密度对比
    params=[route_id]
    SQL: `SELECT CASE p.up_or_down WHEN '1' THEN '上行' WHEN '2' THEN '下行' ELSE '未填' END AS 方向, COUNT(*) AS 处数, ROUND(AVG(p.area),3) AS 平均面积 FROM ai_problem p WHERE p.del_flag=0 AND p.routes_id='{route_id}' GROUP BY 方向`

15d. **route_type_area_share**｜某条路各病害类型的数量占比与面积占比
    params=[route_id]
    SQL: `SELECT COALESCE(b.problem_type,'未识别') AS 类型, COUNT(*) AS 处数, ROUND(COUNT(*)*100.0/SUM(COUNT(*)) OVER (),1) AS 数量占比, ROUND(SUM(p.area),1) AS 面积, ROUND(SUM(p.area)*100.0/SUM(SUM(p.area)) OVER (),1) AS 面积占比 FROM ai_problem p LEFT JOIN ai_problem_base b ON p.damage_type=b.problem_code WHERE p.del_flag=0 AND p.routes_id='{route_id}' GROUP BY 类型 ORDER BY 处数 DESC`

15e. **disease_size_top**｜某条路面积最大的 N 处病害明细
    params=[route_id, top_n]
    SQL: `SELECT p.pile_number AS 桩号, b.problem_type AS 类型, p.area AS 面积, p.collection_time AS 时间 FROM ai_problem p LEFT JOIN ai_problem_base b ON p.damage_type=b.problem_code WHERE p.del_flag=0 AND p.routes_id='{route_id}' ORDER BY p.area DESC LIMIT {top_n}`
    match: shape=[top,list], subject=[disease], require_limit=true

15f. **monthly_new_disease**｜某条路每月新增病害数趋势
    params=[route_id]
    SQL: `SELECT DATE_FORMAT(p.collection_time,'%Y-%m') AS 月份, COUNT(*) AS 新增处数, ROUND(SUM(p.area),1) AS 新增面积 FROM ai_problem p WHERE p.del_flag=0 AND p.routes_id='{route_id}' GROUP BY 月份 ORDER BY 月份`

### H. 构造物 × 路线交互（桥/隧/边坡挂到具体路线上问）
16. **route_bridge_count**｜某条路有多少座桥
    params=[route_id]
    SQL: `SELECT r.short_name AS 路线, COUNT(*) AS 桥梁座数, ROUND(SUM(CASE b.span_category WHEN '1' THEN 1 ELSE 0 END),0) AS 其中特大桥 FROM basic_facilities_bridges b JOIN basic_facilities_routes r ON b.routes_id=r.id WHERE b.del_flag=0 AND b.routes_id='{route_id}' GROUP BY r.short_name`

16b. **route_tunnel_count**｜某条路有多少条隧道、总长多少
    params=[route_id]
    SQL: `SELECT r.short_name AS 路线, COUNT(*) AS 隧道座数, ROUND(SUM(t.tunnel_length),1) AS 隧道总长_米 FROM basic_facilities_tunnels t JOIN basic_facilities_routes r ON t.belong_route_id=r.id WHERE t.del_flag=0 AND t.belong_route_id='{route_id}' GROUP BY r.short_name`

16c. **route_slope_count**｜某条路有多少处边坡、总高多少
    params=[route_id]
    SQL: `SELECT r.short_name AS 路线, COUNT(*) AS 边坡处数, ROUND(SUM(s.height),1) AS 边坡总高_米 FROM basic_facilities_slope s JOIN basic_facilities_routes r ON s.routes_id=r.id WHERE s.del_flag=0 AND s.routes_id='{route_id}' GROUP BY r.short_name`

16d. **route_all_structures**｜某条路上桥/隧/边坡一览（按桩号顺序）
    params=[route_id]
    SQL: `SELECT '桥梁' AS 类型, b.name AS 名称, b.middle_num AS 桩号 FROM basic_facilities_bridges b WHERE b.del_flag=0 AND b.routes_id='{route_id}' UNION ALL SELECT '隧道', t.name, t.stake_center_num FROM basic_facilities_tunnels t WHERE t.del_flag=0 AND t.belong_route_id='{route_id}' UNION ALL SELECT '边坡', s.name, s.start_num FROM basic_facilities_slope s WHERE s.del_flag=0 AND s.routes_id='{route_id}' ORDER BY 桩号 LIMIT 300`
    scope: 一条路上所有构造物按桩号串起来，看沿线分布

16e. **route_longest_tunnel**｜某条路最长的隧道
    params=[route_id]
    SQL: `SELECT t.name AS 隧道名称, t.tunnel_length AS 长度_米, t.tunnel_clear_width AS 净宽 FROM basic_facilities_tunnels t WHERE t.del_flag=0 AND t.belong_route_id='{route_id}' ORDER BY t.tunnel_length DESC LIMIT 1`

16f. **route_tallest_slope**｜某条路最高的边坡
    params=[route_id]
    SQL: `SELECT s.name AS 边坡名称, s.height AS 高度_米, s.length AS 长度_米, s.start_num FROM basic_facilities_slope s WHERE s.del_flag=0 AND s.routes_id='{route_id}' ORDER BY s.height DESC LIMIT 1`

16g. **routes_structure_compare**｜哪条路桥多/隧道长/边坡多（跨路线对比）
    SQL: `SELECT r.short_name AS 路线, COUNT(DISTINCT b.id) AS 桥梁座数, COUNT(DISTINCT t.id) AS 隧道座数, ROUND(SUM(DISTINCT t.tunnel_length),1) AS 隧道总长, COUNT(DISTINCT s.id) AS 边坡处数 FROM basic_facilities_routes r LEFT JOIN basic_facilities_bridges b ON b.routes_id=r.id AND b.del_flag=0 LEFT JOIN basic_facilities_tunnels t ON t.belong_route_id=r.id AND t.del_flag=0 LEFT JOIN basic_facilities_slope s ON s.routes_id=r.id AND s.del_flag=0 WHERE r.del_flag=0 GROUP BY r.id, r.short_name ORDER BY 桥梁座数 DESC`
    scope: 每条路的桥/隧/边坡数量一表对比；空表如实答 0

### F. 时间/对比（业务问题5：长时间变化）
15. **route_month_area_trend**｜某条路逐月处数+总面积趋势
    params=[route_id]
    SQL: `SELECT DATE_FORMAT(p.collection_time,'%Y-%m') AS 月份, COUNT(*) AS 处数, ROUND(SUM(p.area),2) AS 总面积 FROM ai_problem p WHERE p.del_flag=0 AND p.routes_id='{route_id}' GROUP BY 月份 ORDER BY 月份`
    match: shape=[trend,distribution], subject=[disease], slots=[route], group_by=[month], metrics=[count,total_area]

16. **patrol_new_vs_previous**｜某条路本次巡检比上次新增多少处病害
    params=[route_id]
    SQL: 子查询取该路最近两次巡检的采集日期，分别 COUNT(*) 再相减（在 SQL 里用两次 MAX(collection_time) 求各自日期，再分别统计）。

## 四、要求
1. 列名先按本方案写，上线前用 information_schema 对齐各表真实列名（尤其 maintenance_*/project_* 的列名我没连库，给的是占位）；空表如实答 0/空，不硬凑；

### 5.2 与方案不同的取舍（都有理由）

1. **无参数模板一律不给 `match`**：现有 36 条里所有无参数模板的 `match` 都是 null（惯例）。
   给它们写 `shape+subject` 级别的 match 会"张冠李戴"——实测 `{shape:[distribution],subject:[asset]}`
   这种声明会把"各隧道的照明情况"也接走。它们照样在「快捷查询」里能点，只是不参与自动匹配。
2. **`date_from` / `date_to` 落地了**：不是摆设——`preset_lib.bind` 增加了"自由日期按格式校验"
   （没有枚举白名单，用 `^\d{4}-\d{2}-\d{2}$` 兜注入），`/api/preset-queries` 把参数的 `type`
   透给前端（`type: time` → 日期选择器），并配了 2 条真正用它的模板
   （`route_disease_period` / `route_disease_period_by_type`，起止都是**闭区间**）。
3. **对比类模板不会自动匹配**：`preset_lib.match_templates` 对 `comparison` 计划直接弃权
   （既有设计："对比题交给 LLM"）。所以 `route_direction_density` / `route_disease_area_compare`
   只供手动点，这是设计使然、不是没写对。
4. **方案 15（`route_density_rank` 补每公里面积）没做**：那是改动已有模板的口径，超出"扩充"范围。
5. **方案 16（`patrol_new_vs_previous` 本次比上次）没做**：巡检任务维度在库里取不到
   "上次"的稳定口径（patrol 表没有路线/桩号字段），改成 `route_patrol_history`
   （某条路最近几次巡检各检出多少处病害），口径可复核。
