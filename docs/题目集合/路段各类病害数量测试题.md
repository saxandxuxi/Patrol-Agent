# 路段各类病害数量 测试题（3 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据背景

### 病害有两个分类字段

1. 具体类型 `ai_problem.damage_type`，对应字典表 `ai_problem_base.problem_code`，如 10 泛油、05 沉陷、08 坑槽。该字段识别率低，大量病害为空，即未识别具体类型。
2. 病害大类 `ai_problem.categories_type`，0 路面病害、5 路基病害、10 沿路设施、15 交安事件。该字段基本都有值。

病害通过 `sections_id` 关联路段表 `basic_facilities_sections` 取路段名称。

### 两个必须注意的口径坑

1. 前导零不一致：病害表沉陷存的是 `damage_type='5'`，字典表里沉陷的代码是 `'05'`。直接按 `problem_code = damage_type` 连接会匹配不到沉陷，需要用 `LPAD(damage_type,2,'0')` 补零后匹配。
2. 字典表 `problem_code` 不唯一，连字典表统计必须用 `COUNT(DISTINCT p.id)`，否则行数会被放大。

### 各路段病害实查分布

按具体类型：

| 路段 | 泛油 | 沉陷 | 未识别具体类型 | 合计 |
|---|---|---|---|---|
| 宝安大道西乡段 | 534 | 0 | 377 | 911 |
| 宝安中心--恒明珠 | 402 | 16 | 331 | 749 |
| 未知路段 | 0 | 0 | 42 | 42 |

按大类：

| 路段 | 路面病害 | 沿路设施 | 交安事件 | 合计 |
|---|---|---|---|---|
| 宝安大道西乡段 | 546 | 263 | 102 | 911 |
| 宝安中心--恒明珠 | 456 | 229 | 64 | 749 |
| 未知路段 | 27 | 13 | 2 | 42 |

全库汇总：泛油 936 处、沉陷 16 处、未识别具体类型 750 处；路面病害 1029 处、沿路设施 505 处、交安事件 168 处。

## 二、题目与标准答案

### 题1：单路段某具体类型数量

**题目**

宝安大道西乡段检出的泛油病害有多少处？

**标准答案**

534 处。

**考点**

- 泛油代码为 `damage_type='10'`。
- 病害通过 `sections_id` JOIN 路段表，按路段名称限定。
- 未识别具体类型的 377 条不计入泛油。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 泛油数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.damage_type = '10';
```

### 题2：单路段病害大类构成

**题目**

宝安大道西乡段检出的路面病害、沿路设施病害和交安事件分别有多少处？

**标准答案**

- 路面病害：546 处。
- 沿路设施病害：263 处。
- 交安事件：102 处。

合计 911 处，与西乡段病害总数一致。

**考点**

- 用大类字段 `categories_type`，0 路面、10 沿路设施、15 交安。
- 这题统计大类，不依赖具体类型，不受 `damage_type` 大量为空的影响。
- 三类数量之和应等于该路段总数 911。

**正确 SQL 口径**

```sql
SELECT p.categories_type, COUNT(DISTINCT p.id) AS 病害数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
GROUP BY p.categories_type;
```

### 题3：跨路段查某类病害，考前导零口径

**题目**

哪些路段检出了沉陷病害？分别有多少处？

**标准答案**

- 宝安中心--恒明珠段：16 处。
- 宝安大道西乡段：0 处。
- 其他路段：0 处。

全部 16 处沉陷都位于宝安中心--恒明珠段。

**考点**

- 病害表沉陷存的是 `damage_type='5'`，字典表代码是 `'05'`，不补零直接连接会查不到沉陷，错误地回答全部为 0。
- 正确匹配用 `LPAD(p.damage_type,2,'0') = '05'`，或直接用 `damage_type='5'`。
- 沉陷只在恒明珠段出现，西乡段确实为 0，系统应如实区分。

**正确 SQL 口径**

```sql
SELECT s.full_name, COUNT(DISTINCT p.id) AS 沉陷数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND LPAD(p.damage_type, 2, '0') = '05'
GROUP BY s.full_name;
```

## 三、验收检查项

1. 题1 答案为 534，不能把未识别的 377 条算进泛油。
2. 题2 答案为路面 546、沿路设施 263、交安 102，三者之和等于 911。
3. 题3 恒明珠段沉陷为 16，西乡段为 0；若系统对所有路段都答 0，说明沉陷代码前导零没有处理。
4. 连字典表统计一律用 `COUNT(DISTINCT p.id)`，避免字典表不唯一导致行数放大。
5. 未识别具体类型的病害应如实说明，不能丢弃，也不能随意归入泛油或其他类型。
