# 固定长度区间内病害类型与数量统计 测试题（5 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据背景

### 病害位置用桩号米数表达

病害表 `ai_problem` 中沿道路方向的位置由以下字段表达：

- `pile_number`：文本桩号，如 `k0+002`。
- `pile_distance`：解析后的桩号米数，如 `k0+002` 对应 2，`K0+200` 对应 200。
- `pile_meter`：距路段起点的米数，本库与 `pile_distance` 取值一致。

统计某段长度内的病害，先把文本桩号换算成米数，再用 `pile_distance` 做区间筛选。

### 桩号区间必须先限定路段

不同路段的桩号都从 K0+000 起算。西乡段和恒明珠段都存在 K0+000 到 K0+900 这一段，不限定路段直接按桩号筛，会把多条路段的数据混在一起。因此区间统计必须先 JOIN 路段表、限定到具体路段。

### 各路段桩号范围

- 宝安大道西乡段：K0+011 至 K0+887，共 911 条病害。
- 宝安中心--恒明珠：K0+002 至 K20+000，共 749 条。
- 未知路段：42 条，无桩号。

## 二、题目与标准答案

### 题1：固定区间内的病害总数

**题目**

宝安大道西乡段 K0+000 到 K0+200 这一段，一共有多少处病害？

**标准答案**

198 处。

**考点**

- K0+000 换算为 0 米，K0+200 换算为 200 米，用 `pile_distance BETWEEN 0 AND 200`。
- 必须先限定西乡段，避免混入恒明珠段同桩号的数据。
- 该段泛油 113 处、未识别 85 处，合计 198。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 病害数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.pile_distance BETWEEN 0 AND 200;
```

### 题2：固定区间内的病害类型构成

**题目**

宝安大道西乡段 K0+000 到 K0+200 这一段，泛油病害有多少处？

**标准答案**

113 处。该段另有未识别具体类型的病害 85 处，合计 198 处。

**考点**

- 在区间条件上叠加 `damage_type='10'` 泛油。
- 区间筛选与类型筛选同时生效。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 泛油数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.pile_distance BETWEEN 0 AND 200
  AND p.damage_type = '10';
```

### 题3：区间边界与相邻区间

**题目**

宝安大道西乡段 K0+200 到 K0+400 这一段，泛油病害有多少处？

**标准答案**

117 处。其中 K0+200 至 K0+300 有 58 处，K0+300 至 K0+400 有 59 处。

**考点**

- 该段为前开后闭区间，用 `pile_distance > 200 AND pile_distance <= 400`，避免与题1 的 K0+200 边界重复计数。
- 结果由两个 100 米段相加，58 加 59 等于 117。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 泛油数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.pile_distance > 200
  AND p.pile_distance <= 400
  AND p.damage_type = '10';
```

### 题4：固定长度分段，找病害最密集的一段

**题目**

宝安大道西乡段按每 100 米划一段，哪一个 100 米段的病害最多？有多少处？

**标准答案**

K0+800 至 K0+900 这一段最多，共 136 处，其中泛油 81 处、未识别 55 处。

**考点**

- 用 `FLOOR(pile_distance / 100) * 100` 计算每条病害所属的 100 米段起点。
- 按段起点分组、计数、降序取第一段。
- 不能直接拉取 500 条明细再人工数，必须在数据库里聚合。

**正确 SQL 口径**

```sql
SELECT FLOOR(p.pile_distance / 100) * 100 AS 段起点米数,
       COUNT(*) AS 病害数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.pile_distance IS NOT NULL
GROUP BY 段起点米数
ORDER BY 病害数量 DESC
LIMIT 1;
```

### 题5：另一路段、1000 米区间、多类型

**题目**

宝安中心--恒明珠段 K0+000 到 K1+000 这 1000 米内，各类病害分别有多少处？

**标准答案**

- 泛油：93 处。
- 沉陷：4 处。
- 未识别具体类型：99 处。

合计 196 处。

**考点**

- K1+000 换算为 1000 米，区间为 `pile_distance BETWEEN 0 AND 1000`。
- 限定到恒明珠段，该段桩号延伸到 K20+000，与西乡段同桩号但不是同一批数据。
- 该区间内三种类型都有，沉陷代码为 `damage_type='5'`。

**正确 SQL 口径**

```sql
SELECT p.damage_type, COUNT(*) AS 病害数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安中心--恒明珠'
  AND p.pile_distance BETWEEN 0 AND 1000
GROUP BY p.damage_type;
```

## 三、验收检查项

1. 所有区间统计都必须先限定路段，再按桩号米数筛，不能跨路段混算。
2. 文本桩号要正确换算成米数，K0+200 为 200、K1+000 为 1000。
3. 题1 答案 198，题2 答案 113，题3 答案 117，注意题1 与题3 的边界不重复。
4. 题4 必须用 `FLOOR` 分组聚合后取最大，不能拉明细或默认返回前 500 条。
5. 题5 答案为泛油 93、沉陷 4、未识别 99，合计 196，限定在恒明珠段。
6. 各段类型数量之和应与该路段总数一致，西乡段 9 个分段合计 911。
