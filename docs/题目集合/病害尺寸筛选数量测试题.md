# 按病害尺寸筛选数量 测试题（5 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`，全库病害共 1702 条。

## 一、数据现状（出题前必须知道）

1. 库中没有"裂缝"类型的病害。病害具体类型字段 `damage_type` 只有三种取值：10 泛油 936 条、5 沉陷 16 条、空 750 条（未识别具体类型）。网状裂缝、纵向裂缝等字典里虽有定义，但没有对应数据。系统若被问"裂缝"，应如实回答库中没有该类型，不能编造数量。下文以实际存在的泛油（同样是线性病害）替代出题。
2. 病害长度字段 `disease_length` 全库为空，不能直接用。但字段 `area_height` 高度和 `area_width` 宽度都有值，`disease_length` 的定义就是两者取大，单位米，因此病害长度要用 `GREATEST(area_height, area_width)` 现算。
3. 面积字段 `area` 有值，单位平方米，实测 `area = area_height × area_width`。1660 条有面积，另 42 条为 0 或空。

## 二、实查尺寸分布

病害长度（高宽取大）：

| 长度区间 | 数量 |
|---|---|
| 不超过 2 米 | 951 |
| 2 到 5 米 | 609 |
| 5 到 10 米 | 81 |
| 大于 10 米 | 61 |

汇总：大于 2 米共 751 处，总长度 6557.0 米；大于 5 米 142 处；大于 10 米 61 处。

按类型，大于 2 米的有：泛油 466 处、沉陷 16 处（沉陷全部为 3.0 米）、未识别 269 处。

面积：大于 10 平方米 60 处；大于 100 平方米 19 处，总面积 95000 平方米。

## 三、题目与标准答案

### 题1：全库病害长度大于 2 米（数量加总数量）

**题目**

病害长度大于 2 米的有多少处？这些病害的总长度是多少米？

**标准答案**

751 处，总长度 6557.0 米。

**考点**

- 长度字段 `disease_length` 为空，必须用 `GREATEST(area_height, area_width)` 现算。
- 数量用 `COUNT`，总长度用 `SUM`，两个结果都要给。
- 不能因为长度字段为空就回答无法查询。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 数量,
       ROUND(SUM(GREATEST(area_height, area_width)), 1) AS 总长度
FROM ai_problem
WHERE del_flag = 0
  AND GREATEST(area_height, area_width) > 2;
```

### 题2：某类病害长度大于 2 米（对应裂缝场景，用泛油）

**题目**

长度大于 2 米的泛油病害有多少处？总长度是多少米？

**标准答案**

466 处，总长度 1575.8 米。

**考点**

- 泛油代码为 `damage_type='10'`。
- 在类型条件上叠加长度条件。
- 泛油中另有 470 处长度不超过 2 米，466 加 470 等于泛油总数 936。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 数量,
       ROUND(SUM(GREATEST(area_height, area_width)), 1) AS 总长度
FROM ai_problem
WHERE del_flag = 0
  AND damage_type = '10'
  AND GREATEST(area_height, area_width) > 2;
```

### 题3：长度小于等于 2 米

**题目**

病害长度不超过 2 米的有多少处？

**标准答案**

951 处。

**考点**

- 不超过 2 米对应 `<= 2`。
- 951 与题1的 751 之和等于全库总数 1702，可用于自证。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 数量
FROM ai_problem
WHERE del_flag = 0
  AND GREATEST(area_height, area_width) <= 2;
```

### 题4：面积大于 100 平方米

**题目**

面积大于 100 平方米的病害有多少处？总面积是多少？

**标准答案**

19 处，总面积 95000 平方米。其中宝安大道西乡段 11 处共 55000 平方米，宝安中心--恒明珠段 8 处共 40000 平方米。

**考点**

- 面积用 `area` 字段，单位平方米，不要用长度代替。
- 这些大面积病害均为未识别具体类型，泛油最大面积只有 7.52 平方米，不属于此类。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 数量,
       ROUND(SUM(area), 1) AS 总面积
FROM ai_problem
WHERE del_flag = 0
  AND area > 100;
```

### 题5：限定路段加长度条件

**题目**

宝安大道西乡段长度大于 2 米的病害有多少处？总长度是多少米？

**标准答案**

399 处，总长度 3638.1 米。

**考点**

- 病害通过 `sections_id` JOIN 路段表，按路段名称限定。
- 同时叠加路段条件和长度条件。
- 长度仍用 `GREATEST(area_height, area_width)` 现算。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 数量,
       ROUND(SUM(GREATEST(p.area_height, p.area_width)), 1) AS 总长度
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND GREATEST(p.area_height, p.area_width) > 2;
```

## 四、验收检查项

1. 长度不能直接取 `disease_length`，该字段全空；系统必须用 `GREATEST(area_height, area_width)` 现算。
2. 题1 答案 751 处、总长 6557.0 米；题3 答案 951 处，二者之和 1702。
3. 题2 答案 466 处、总长 1575.8 米，泛油不超过 2 米的另有 470 处。
4. 题4 答案 19 处、总面积 95000 平方米，按面积字段查，不混入泛油。
5. 题5 答案 399 处、总长 3638.1 米，必须 JOIN 路段表。
6. 若直接问"裂缝"，系统应如实回答库中没有裂缝类型，而不是按字面去匹配或编造数量。
