# 某次巡查检出病害数量与统计 测试题（3 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据背景

### 表关系

- 巡检任务表 `ai_maintain_patrol`：一行是一次巡查，主键 `id`。
- 病害表 `ai_problem`：一行是一条病害，外键 `patrol_id` 指向巡检任务 `id`。
- 一次巡查对应多条病害，用 `ai_problem.patrol_id = ai_maintain_patrol.id` 关联。

### 巡检任务关键字段

- `task_number`：任务编号，例如 `XJJL202607210004`。
- `patrol_name`：巡查名称。
- `patrol_type`：巡查类型，0 定期巡查、5 日常巡查、10 专项巡查、15 复核考评、20 重点抽查。
- `patrol_status`：巡查状态，0 未开始、5 进行中、10 暂停、15 已完成、20 逾期。
- `patrol_mileage`：巡检里程。
- `create_time`：巡查创建时间。
- `end_date`：截至日期。

### 病害统计相关字段

- `damage_type`：病害类型代码，代码 10 表示泛油。
- `problem_source`：病害来源，0 手动新增、5 车辆巡检、10 人工巡检、15 新增历史工单、20 路长转养护、25 路政转养护。
- 病害中文名称在字典表 `ai_problem_base`，用 `problem_code` 对 `damage_type`。

### 全库实查事实

- 巡检任务共 148 次，其中定期巡查 147 次。
- 病害共 1702 条，全部为车辆巡检，且每条病害都关联了巡检。
- 巡检时间范围：2025-06-11 至 2026-07-30。

### 一个必须避开的坑：JOIN 字典表会放大行数

字典表 `ai_problem_base` 只有 84 行，`problem_code` 不唯一，同一个病害代码下有多行。

直接写 `LEFT JOIN ai_problem_base b ON b.problem_code = ai_problem.damage_type` 再 `COUNT(*)`，会把一次巡查的 106 条病害放大成 166 条，泛油从 60 处放大成 120 处。

正确做法二选一：

1. 不连字典表，按代码直接统计，例如 `WHERE damage_type='10'`。
2. 需要中文名称时，连表统计必须用 `COUNT(DISTINCT ai_problem.id)`，或使用 MDL 中已去重的 `damage_dict` 模型。

## 二、题目与标准答案

### 题1：某次巡查的检出总量（基础）

**题目**

任务编号 XJJL202607210004 的这次巡查，一共检出了多少处病害？

**标准答案**

106 处。

**统计口径**

- 用 `task_number` 定位巡检任务，再按 `patrol_id` 关联病害表计数。
- 病害只统计 `del_flag=0`。
- 该次巡查为定期巡查，2026-07-21 创建，巡检里程 913，状态已完成。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 病害数量
FROM ai_problem p
JOIN ai_maintain_patrol t ON t.id = p.patrol_id
WHERE p.del_flag = 0
  AND t.task_number = 'XJJL202607210004';
```

### 题2：某次巡查某类病害的数量（考字典表 JOIN 放大）

**题目**

任务编号 XJJL202607210004 的这次巡查，检出的泛油病害有多少处？

**标准答案**

60 处。该次巡查另有 46 处为未识别类型，合计 106 处。

**易错点**

- 直接 JOIN 字典表并 `COUNT(*)`，会得到 120 处，这是字典表行数放大，错误。
- 正确写法是按泛油代码 `damage_type='10'` 直接统计，或连表后用 `COUNT(DISTINCT p.id)`。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 泛油数量
FROM ai_problem p
JOIN ai_maintain_patrol t ON t.id = p.patrol_id
WHERE p.del_flag = 0
  AND t.task_number = 'XJJL202607210004'
  AND p.damage_type = '10';
```

### 题3：同一天各次巡查的检出数量对比与排名（考时间落库与零值）

**题目**

2026 年 7 月 21 日各次巡查分别检出了多少处病害？哪次最多？

**标准答案**

当天共 15 次巡查，其中 3 次检出病害，其余 12 次为 0 处。

| 任务编号 | 检出病害数 |
|---|---|
| XJJL202607210004 | 106 |
| XJJL202607210000 | 35 |
| XJJL202607210003 | 35 |
| XJJL202607210005 至 XJJL202607210016 等 12 次 | 0 |

最多的是 XJJL202607210004，检出 106 处。

**考点**

- 时间条件落在巡检表 `create_time`，按 `DATE(create_time)='2026-07-21'` 过滤。
- 零病害的巡检不能丢，巡检表必须在左、病害表用 `LEFT JOIN`，否则 12 次零病害巡查会消失。
- 全库范围有并列第一，XJJL202607210004 与 XJJL202607220003 都是 106 处，所以题目限定到 7 月 21 日当天，当天答案唯一。

**正确 SQL 口径**

```sql
SELECT t.task_number, COUNT(DISTINCT p.id) AS 病害数量
FROM ai_maintain_patrol t
LEFT JOIN ai_problem p ON p.patrol_id = t.id AND p.del_flag = 0
WHERE t.del_flag = 0
  AND DATE(t.create_time) = '2026-07-21'
GROUP BY t.id, t.task_number
ORDER BY 病害数量 DESC, t.create_time;
```

## 三、验收检查项

1. 题1 回答 106，不多不少。
2. 题2 回答 60，不能出现 120，出现即说明字典表 JOIN 放大。
3. 题3 必须列出当天 15 次巡查，包含 12 次 0 处，不能只列 3 次有数据的；最多一次答案为 XJJL202607210004。
4. 三道题都通过巡检表和病害表的 `patrol_id` 关联取数，不依赖路线名称。
