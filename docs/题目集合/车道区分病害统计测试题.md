# 按车道区分病害数量 测试题（3 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据现状说明

库里没有"第几车道、超车道、行车道"这种横向车道字段，`basic_facilities_sections.lane_type` 车道特征字段全库 5840 个路段全部为空，不能用来区分。

真正可用的车道维度只有两个：

1. 车道数 `basic_facilities_sections.lane_count`，在路段表，病害要通过 `sections_id` JOIN 路段表才能取到。
2. 上下行 `ai_problem.up_or_down`，病害表自带，1 上行、2 下行、0 全部。

### 车道数取值的真实情况

路段表 5840 个路段中，5839 个 `lane_count` 为 0，这是未填车道数时的默认值，不是"零车道"；只有宝安大道西乡段 1 个路段填了 6，即六车道。

因此病害按车道数只能分成两类：六车道 911 条，车道数未填 791 条。不能把 0 当作一个真实车道数作答。

### 病害实查分布

| 路线 | 车道数 | 上下行 | 病害数 |
|---|---|---|---|
| 宝安大道西乡段 | 6（六车道） | 上行 | 911 |
| 宝安中心--恒明珠 | 未填 | 上行 | 732 |
| 宝安中心--恒明珠 | 未填 | 下行 | 17 |
| 未知路线 | 未填 | 未填 | 42 |

按维度汇总：

- 车道数：六车道 911 条，未填车道数 791 条。
- 上下行：上行 1643 条，下行 17 条，未填上下行 42 条。
- 六车道的 911 条病害全部为上行，下行 0 条。
- 下行方向的 17 条病害全部位于宝安中心--恒明珠段。

JOIN 路段表不放大行数，实测 1702 条 JOIN 后仍为 1702 条。

## 二、题目与标准答案

### 题1：按车道数统计（考 JOIN 路段表）

**题目**

六车道公路上检出的病害一共有多少处？

**标准答案**

911 处，全部位于宝安大道西乡段。

其余 791 处病害所在路段的车道数未填，`lane_count` 为默认值 0，不能算作零车道，也不能算作六车道。

**考点**

- 车道数在路段表，必须用 `ai_problem.sections_id = basic_facilities_sections.id` 关联。
- 用 `lane_count = 6` 筛选六车道。
- 不能把默认值 0 当作真实车道数。

**正确 SQL 口径**

```sql
SELECT COUNT(DISTINCT p.id) AS 六车道病害数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.lane_count = 6;
```

### 题2：按上下行统计（病害自有字段）

**题目**

上行方向和下行方向分别检出了多少处病害？

**标准答案**

- 上行方向：1643 处。
- 下行方向：17 处。
- 另有 42 处病害未填写上下行。

**考点**

- 上下行字段 `up_or_down` 直接在病害表，1 为上行、2 为下行。
- 这一题不需要 JOIN 路段表，按病害表分组即可。
- 未填上下行的 42 条不能丢弃，应如实说明。

**正确 SQL 口径**

```sql
SELECT up_or_down, COUNT(*) AS 病害数量
FROM ai_problem
WHERE del_flag = 0
GROUP BY up_or_down;
```

### 题3：车道数与上下行交叉统计

**题目**

六车道公路上，上行方向和下行方向分别检出了多少处病害？

**标准答案**

- 上行方向：911 处。
- 下行方向：0 处。

六车道的宝安大道西乡段检出的 911 条病害全部为上行方向，没有下行病害。下行方向的 17 条病害全部位于车道数未填的宝安中心--恒明珠段。

**考点**

- 同时满足 `lane_count = 6` 和 `up_or_down` 两个条件。
- 六车道下行结果为 0，系统必须如实回答 0，不能因为全库有 17 条下行病害就错误地算到六车道上。

**正确 SQL 口径**

```sql
SELECT p.up_or_down, COUNT(DISTINCT p.id) AS 病害数量
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.lane_count = 6
GROUP BY p.up_or_down;
```

## 三、验收检查项

1. 题1 必须 JOIN 路段表取车道数，答案为 911，且不把默认值 0 当作零车道。
2. 题2 直接用病害表上下行字段分组，答案为上行 1643、下行 17，并体现未填的 42 条。
3. 题3 六车道上行 911、下行 0，不能把恒明珠段的 17 条下行病害算到六车道上。
4. 各维度汇总应能回到总数 1702：六车道 911 加未填车道数 791；上行 1643 加下行 17 加未填 42。
5. 明确告知系统中没有横向车道编号字段，不编造"第几车道""超车道"这类不存在的分类。
