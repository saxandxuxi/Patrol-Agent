# 路段病害高发桩号与每公里密度 测试题（5 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据背景

### 路段长度的正确口径

路段长度用 `end_meter_total - start_meter_total` 计算，单位米。

| 路段 | 起点总米数 | 终点总米数 | 路段长度 |
|---|---|---|---|
| 宝安大道西乡段 | 0 | 5100 | 5100 米，即 5.10 公里 |
| 宝安中心--恒明珠 | 1 | 10003 | 10002 米，即 10.002 公里 |

不能用 `distance` 字段算长度，西乡段该字段填 5.60，但按起止桩号算只有 5.10，台账手填值实测不准。

### 条状病害换算面积口径

泛油属于条状病害，沿道路方向延伸，长度取 `GREATEST(area_height, area_width)`，标准宽度 0.2 米，因此换算面积为 长度 × 0.2。

实测各路段泛油：

| 路段 | 泛油数量 | 累计长度 | 按 0.2 米换算面积 | 实际面积 |
|---|---|---|---|---|
| 西乡段 | 534 | 1318.5 米 | 263.7 平方米 | 569.8 平方米 |
| 恒明珠 | 402 | 996.8 米 | 199.4 平方米 | 376.0 平方米 |

换算面积与实际面积差异大，因为部分泛油宽度大于 0.2，且实际面积中混入了未识别类型的大面积区域。

### 高发桩号实查

西乡段每 100 米段实际面积：

| 桩号段 | 实际面积 | 病害数 |
|---|---|---|
| K0+800 至 K0+900 | 15183.4 | 136 |
| K0+200 至 K0+300 | 15116.2 | 100 |
| K0+600 至 K0+700 | 10124.0 | 92 |
| K0+500 至 K0+600 | 10109.0 | 99 |
| K0+100 至 K0+200 | 5180.2 | 108 |

西乡段每 100 米段泛油换算面积，最高的是 K0+800 至 K0+900，为 40.5 平方米，对应 81 条泛油。

### 每公里密度实查

- 每公里病害数：西乡段 178.6 处，恒明珠 74.9 处。
- 每公里泛油换算面积：西乡段 51.70 平方米，恒明珠 19.93 平方米。

## 二、题目与标准答案

### 题1：按面积找高发桩号

**题目**

宝安大道西乡段按每 100 米一段，病害面积最突出的是哪一段桩号？面积是多少？

**标准答案**

K0+800 至 K0+900 这一段，病害面积 15183.4 平方米，共 136 条。

K0+200 至 K0+300 段面积 15116.2 平方米，与第一段非常接近，但略低，高发段以 K0+800 段为准。

**考点**

- 用 `FLOOR(pile_distance / 100) * 100` 分段。
- 按段聚合面积并降序取第一段。
- 不能拉取明细人工估计，必须在数据库内聚合。

**正确 SQL 口径**

```sql
SELECT FLOOR(p.pile_distance / 100) * 100 AS 段起点,
       ROUND(SUM(p.area), 1) AS 面积,
       COUNT(*) AS 病害数
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.pile_distance IS NOT NULL
GROUP BY 段起点
ORDER BY 面积 DESC
LIMIT 1;
```

### 题2：条状病害换算面积高发桩号

**题目**

西乡段泛油按 0.2 米宽度换算面积，哪一段桩号的泛油换算面积最大？

**标准答案**

K0+800 至 K0+900 段，换算面积 40.5 平方米，对应 81 条泛油。

**考点**

- 泛油长度用 `GREATEST(area_height, area_width)`，乘以 0.2 得换算面积。
- 仅统计泛油，即 `damage_type='10'`，不混入未识别类型的大面积。
- 按段聚合后取最大。

**正确 SQL 口径**

```sql
SELECT FLOOR(p.pile_distance / 100) * 100 AS 段起点,
       ROUND(SUM(GREATEST(p.area_height, p.area_width) * 0.2), 1) AS 换算面积
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.damage_type = '10'
  AND p.pile_distance IS NOT NULL
GROUP BY 段起点
ORDER BY 换算面积 DESC
LIMIT 1;
```

### 题3：条状病害累计长度与总换算面积

**题目**

西乡段的泛油累计长度一共多少米？按 0.2 米宽度换算，总面积是多少？

**标准答案**

累计长度 1318.5 米，换算总面积 263.7 平方米。

**考点**

- 累计长度用 `SUM(GREATEST(area_height, area_width))`。
- 换算面积用累计长度乘以 0.2。
- 两个结果在同一查询中给出，不能只报数量。

**正确 SQL 口径**

```sql
SELECT ROUND(SUM(GREATEST(p.area_height, p.area_width)), 1) AS 累计长度,
       ROUND(SUM(GREATEST(p.area_height, p.area_width) * 0.2), 1) AS 换算面积
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND s.full_name = '宝安大道西乡段'
  AND p.damage_type = '10';
```

### 题4：每公里病害数量密度

**题目**

西乡段和恒明珠段，每公里平均各有多少处病害？

**标准答案**

- 西乡段：178.6 处每公里。
- 恒明珠：74.9 处每公里。

**考点**

- 路段长度用 `end_meter_total - start_meter_total`，换算成公里。
- 每公里病害数 = 病害总数 ÷ 路段长度公里。
- 西乡段虽然病害多，但密度高主要是因为路段长度短，不能只看总数。

**正确 SQL 口径**

```sql
SELECT s.full_name,
       ROUND(COUNT(DISTINCT p.id) /
             ((s.end_meter_total - s.start_meter_total) / 1000), 1) AS 每公里病害数
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
GROUP BY s.id, s.full_name;
```

### 题5：每公里泛油换算面积密度

**题目**

西乡段和恒明珠段，每公里泛油换算面积分别是多少？

**标准答案**

- 西乡段：51.70 平方米每公里。
- 恒明珠：19.93 平方米每公里。

**考点**

- 泛油换算面积用 长度 × 0.2，再除以路段长度公里。
- 分母仍是台账起止桩号长度，不能用 `distance`。
- 该指标反映条状病害在单位里程上的覆盖程度。

**正确 SQL 口径**

```sql
SELECT s.full_name,
       ROUND(SUM(GREATEST(p.area_height, p.area_width) * 0.2) /
             ((s.end_meter_total - s.start_meter_total) / 1000), 2) AS 每公里换算面积
FROM ai_problem p
JOIN basic_facilities_sections s ON s.id = p.sections_id
WHERE p.del_flag = 0
  AND p.damage_type = '10'
GROUP BY s.id, s.full_name;
```

## 三、验收检查项

1. 路段长度一律用 `end_meter_total - start_meter_total`，不用 `distance` 手填值。
2. 条状病害长度用 `GREATEST(area_height, area_width)`，泛油换算面积为长度 × 0.2。
3. 题1 高发面积段为 K0+800 至 K0+900，15183.4 平方米；K0+200 段 15116.2 略低。
4. 题2 泛油换算面积高发段为 K0+800 至 K0+900，40.5 平方米，不含未识别大面积。
5. 题3 答案为累计长度 1318.5 米、换算面积 263.7 平方米。
6. 题4 答案为西乡段 178.6 处每公里、恒明珠 74.9 处每公里。
7. 题5 答案为西乡段 51.70 平方米每公里、恒明珠 19.93 平方米每公里。
8. 所有高发桩号和密度都必须在数据库内聚合计算，不能拉取 500 条明细后由模型估算。
