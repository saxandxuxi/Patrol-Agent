# 路段指定病害类型的数量与长度统计 测试题（5 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据背景

### 病害类型实际取值

病害表 `ai_problem.damage_type` 实际只有三种取值：



| damage\_type | 类型      | 数量  |
| ------------ | ------- | --- |
| 10           | 泛油      | 936 |
| 5            | 沉陷      | 16  |
| 空            | 未识别具体类型 | 750 |

裂缝在字典 `ai_problem_base` 中有定义，包括网状裂缝 02、纵向裂缝 03、横向裂缝 04、板角断裂 15、裂缝 47 等，但病害表中这些代码的记录为 0 条。系统被问 "裂缝" 时，必须如实回答库中没有该类型，不能因为字典里有定义就编造数量或长度。

### 沉陷代码存在映射陷阱

字典 `ai_problem_base` 中沉陷的代码是 `05`，但病害表 `ai_problem.damage_type` 实际存的是 `5`，泛油代码两边都是 `10`。按沉陷查询时，要匹配病害表真实存储值 `'5'`，或用 `LPAD(damage_type, 2, '0') = '05'` 做归一化，不能直接拿字典的 `'05'` 去等，否则会漏数。

### 长度口径

长度字段 `disease_length` 全库为空，病害长度用 `GREATEST(area_height, area_width)` 现算，面积用 `area` 字段。

### 各路段分类型实查



| 路段  | 类型  | 数量  | 总长度（米） | 面积（平方米） |
| --- | --- | --- | ------ | ------- |
| 西乡段 | 泛油  | 534 | 1318.5 | 569.8   |
| 西乡段 | 未识别 | 377 | 2830.2 | 55671.4 |
| 恒明珠 | 泛油  | 402 | 996.8  | 376.0   |
| 恒明珠 | 沉陷  | 16  | 48.0   | 48.0    |
| 恒明珠 | 未识别 | 331 | 2170.2 | 40513.0 |

沉陷 16 条全部在恒明珠段，每条长度均为 3.0 米，西乡段没有沉陷。

## 二、题目与标准答案

### 题 1：裂缝总长度（字典有定义、实际无数据）

**题目**

宝安大道西乡段的裂缝总长度是多少？

**标准答案**

库中没有裂缝类型的病害，长度为 0 米。

裂缝相关代码（网状裂缝 02、纵向裂缝 03、横向裂缝 04、裂缝 47 等）在病害字典里都有定义，但病害表中没有任何一条对应记录。系统应如实回答没有数据，而不是返回字典里的类型，也不能编造长度。

**考点**



* 类型代码能映射到，但查询结果为 0 条时，要明确告知无数据。

* 不能把字典里的裂缝类型当作实际存在的病害。

**正确 SQL 口径**



```
SELECT COUNT(\*) AS 裂缝数量,

&#x20;      COALESCE(SUM(GREATEST(area\_height, area\_width)), 0) AS 总长度

FROM ai\_problem

WHERE del\_flag = 0

&#x20; AND damage\_type IN ('02','03','04','15','47');
```

### 题 2：某路段泛油总长度

**题目**

宝安大道西乡段的泛油病害一共有多少处？总长度是多少米？

**标准答案**

534 处，总长度 1318.5 米。

**考点**



* 泛油代码 `damage_type='10'`。

* 长度用 `GREATEST(area_height, area_width)` 现算。

* 数量和总长度两个结果都要给。

**正确 SQL 口径**



```
SELECT COUNT(\*) AS 泛油数量,

&#x20;      ROUND(SUM(GREATEST(area\_height, area\_width)), 1) AS 总长度

FROM ai\_problem

WHERE del\_flag = 0

&#x20; AND sections\_id = (SELECT id FROM basic\_facilities\_sections WHERE full\_name = '宝安大道西乡段')

&#x20; AND damage\_type = '10';
```

### 题 3：沉陷总长度（代码映射陷阱）

**题目**

宝安中心 -- 恒明珠段的沉陷病害有多少处？总长度是多少米？

**标准答案**

16 处，总长度 48.0 米，每条长度均为 3.0 米。

**考点**



* 字典中沉陷代码是 `05`，病害表实际存的是 `5`，必须按病害表真实值匹配，否则查不到。

* 沉陷全部集中在恒明珠段，西乡段为 0 条。

**正确 SQL 口径**



```
SELECT COUNT(\*) AS 沉陷数量,

&#x20;      ROUND(SUM(GREATEST(area\_height, area\_width)), 1) AS 总长度

FROM ai\_problem

WHERE del\_flag = 0

&#x20; AND sections\_id = (SELECT id FROM basic\_facilities\_sections WHERE full\_name = '宝安中心--恒明珠')

&#x20; AND LPAD(damage\_type, 2, '0') = '05';
```

### 题 4：指定类型的数量、长度、面积

**题目**

宝安中心 -- 恒明珠段的泛油病害有多少处？总长度和面积分别是多少？

**标准答案**

402 处，总长度 996.8 米，面积 376.0 平方米。

**考点**



* 一次给出数量、长度、面积三个指标。

* 长度用 `GREATEST(area_height, area_width)`，面积用 `area`，两者口径不同。

* 泛油是条状病害，面积远小于未识别类型的大面积区域。

**正确 SQL 口径**



```
SELECT COUNT(\*) AS 泛油数量,

&#x20;      ROUND(SUM(GREATEST(area\_height, area\_width)), 1) AS 总长度,

&#x20;      ROUND(SUM(area), 1) AS 总面积

FROM ai\_problem

WHERE del\_flag = 0

&#x20; AND sections\_id = (SELECT id FROM basic\_facilities\_sections WHERE full\_name = '宝安中心--恒明珠')

&#x20; AND damage\_type = '10';
```

### 题 5：两路段同类型长度对比

**题目**

西乡段和恒明珠段的泛油总长度分别是多少米？

**标准答案**



* 西乡段：1318.5 米，534 处。

* 恒明珠段：996.8 米，402 处。

**考点**



* 按路段分组，统计同一种病害的长度。

* 路段通过 `sections_id` 关联路段表，不使用字典表。

* 两个路段结果同时给出，不能只返回一个。

**正确 SQL 口径**



```
SELECT s.full\_name AS 路段,

&#x20;      COUNT(\*) AS 泛油数量,

&#x20;      ROUND(SUM(GREATEST(p.area\_height, p.area\_width)), 1) AS 总长度

FROM ai\_problem p

JOIN basic\_facilities\_sections s ON s.id = p.sections\_id

WHERE p.del\_flag = 0

&#x20; AND p.damage\_type = '10'

GROUP BY s.full\_name;
```

## 三、验收检查项



1. 题 1 裂缝答案为 0 处、0 米，系统必须如实说明字典有定义但无数据，不得编造。

2. 题 2 答案为 534 处、1318.5 米，限定在西乡段。

3. 题 3 沉陷必须命中病害表的 `'5'`，答案为 16 处、48.0 米；若直接按字典 `'05'` 等值查询会得到 0 条。

4. 题 4 答案为 402 处、996.8 米、376.0 平方米，长度和面积口径分开。

5. 题 5 答案为西乡段 1318.5 米、恒明珠段 996.8 米，两个路段都要返回。

6. 所有长度一律用 `GREATEST(area_height, area_width)` 现算，不使用全空的 `disease_length`。

7. 统计类型时不连接字典表，避免字典表 `problem_code` 不唯一导致行数放大；代码映射在条件中直接归一化。
