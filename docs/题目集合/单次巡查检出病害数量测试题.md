## 一、数据背景

### 表关系

- 巡检任务表 `ai_maintain_patrol`：一行是一次巡查，主键 `id`，`task_number` 是任务编号。
- 病害表 `ai_problem`：一行是一条病害，外键 `patrol_id` 指向巡检任务 `id`，`routes_id` 记录病害实际落点路线。
- 路线关联表 `ai_maintain_routes_patrol`：记录某次巡检经过哪些路线，字段为 `patrol_id`、`routes_id`。
- 路线台账 `basic_facilities_routes`：`id` 是路线主键，`short_name` 是路线简称。

### 病害关键字段

- `categories_type`：病害大类，0 路面病害、5 路基病害、10 沿路设施、15 交安事件。
- `damage_type`：病害细分代码，代码 10 在字典中对应泛油，空值表示未识别，细分代码与字典两位编码不严格对应。
- `up_or_down`：上下行，1 上行、2 下行。
- `area`：病害面积，单位为平方米。
- `routes_id`：病害实际落点路线，采集时定位。
- `problem_source`：病害来源，5 车辆巡检。

### 必须避开的坑

#### 1. 病害总数必须按任务编号定位后关联病害表统计

病害表本身没有任务编号，必须通过 `patrol_id` 关联巡检任务表，用 `task_number` 过滤。直接在病害表按其他字段猜任务会得到错误结果。

#### 2. 病害大类合计必须等于总量

按 `categories_type` 分组统计后，各组合计必须与总量一致，可用于对账。任务 XJJL202610310000 的大类合计 8162 与总量一致。

#### 3. 病害落点路线与任务关联路线是两套口径

任务经过哪些路线由路线关联表 `ai_maintain_routes_patrol` 登记，病害具体落在哪条路线由病害表 `routes_id` 在采集时定位，两者独立。该任务关联表登记了未知路线，病害表却没有任何病害落点在未知路线，统计病害分布时以病害表 `routes_id` 为准。

#### 4. 面积统计注意空值和测试异常值

病害面积存在 0 值和 5000 平方米的测试异常值，统计面积合计和平均值时按业务需要决定是否剔除，但数量统计不受影响。

## 二、题目与标准答案

### 题1：单次巡查的病害总量

**题目**

任务编号 XJJL202610310000 的这次巡查，一共检出多少处病害？

**标准答案**

8162 处。

**统计口径**

- 用 `task_number` 在巡检任务表定位任务，再按 `patrol_id` 关联病害表。
- 病害只统计 `del_flag=0`。
- 全部病害来源为车辆巡检，不需要按来源过滤。

**正确 SQL 口径**

```sql
SELECT COUNT(*) AS 病害数量
FROM ai_problem pr
JOIN ai_maintain_patrol p ON p.id = pr.patrol_id
WHERE pr.del_flag = '0'
  AND p.del_flag = '0'
  AND p.task_number = 'XJJL202610310000';
```

### 题2：单次巡查按病害大类的数量分布

**题目**

任务编号 XJJL202610310000 检出的 8162 处病害，按路面病害、路基病害、沿路设施、交安事件四个大类分别有多少处？

**标准答案**

路面病害 7192 处、沿路设施 461 处、路基病害 6 处、交安事件 503 处，合计 8162 处。

**统计口径**

- 按 `categories_type` 分组，0 路面病害、5 路基病害、10 沿路设施、15 交安事件。
- 该任务没有未分类记录，四类合计等于总量 8162。
- 分组结果按数量降序排列。

**正确 SQL 口径**

```sql
SELECT CASE pr.categories_type
         WHEN '0'  THEN '路面病害'
         WHEN '5'  THEN '路基病害'
         WHEN '10' THEN '沿路设施'
         WHEN '15' THEN '交安事件'
         ELSE '未分类' END AS 病害大类,
       COUNT(*) AS 处数
FROM ai_problem pr
JOIN ai_maintain_patrol p ON p.id = pr.patrol_id
WHERE pr.del_flag = '0'
  AND p.del_flag = '0'
  AND p.task_number = 'XJJL202610310000'
GROUP BY pr.categories_type
ORDER BY 处数 DESC;
```

### 题3：单次巡查按路线落点的病害数量分布

**题目**

任务编号 XJJL202610310000 检出的 8162 处病害，分别落在哪些路线、各有多少处？该任务在路线关联表中登记的路线有哪些？

**标准答案**

病害按落点路线分布为长沙－芷江高速公路 7977 处、长沙绕城高速 184 处、许昌-广州 1 处，合计 8162 处。

该任务在路线关联表中登记的路线为未知路线、长沙绕城高速、长沙－芷江高速公路三条，与病害落点分布并不一致。病害表没有任何病害落点在未知路线，统计病害数量分布以病害表的 `routes_id` 为准。

**统计口径**

- 病害按 `routes_id` 关联路线台账取路线简称分组。
- 任务关联路线通过巡检任务表关联路线关联表取路线简称。
- 两套口径分别查询后对比，登记了未知路线不代表有病害落在未知路线。

**正确 SQL 口径（病害落点分布）**

```sql
SELECT r.short_name AS 路线,
       COUNT(*) AS 处数
FROM ai_problem pr
JOIN ai_maintain_patrol p ON p.id = pr.patrol_id
JOIN basic_facilities_routes r ON r.id = pr.routes_id
WHERE pr.del_flag = '0'
  AND p.del_flag = '0'
  AND p.task_number = 'XJJL202610310000'
GROUP BY r.short_name
ORDER BY 处数 DESC;
```

**正确 SQL 口径（任务关联路线）**

```sql
SELECT r.short_name AS 路线
FROM ai_maintain_patrol p
JOIN ai_maintain_routes_patrol rp ON rp.patrol_id = p.id AND rp.del_flag = '0'
JOIN basic_facilities_routes r ON r.id = rp.routes_id
WHERE p.del_flag = '0'
  AND p.task_number = 'XJJL202610310000';
```
