# 区分上下行病害数量统计 测试题（10 道）

答案均为 2026-11-04 16:00 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

本套题围绕病害表的上下行字段展开，覆盖全库总数对比、单次任务、单条路线、病害大类交叉、病害细分代码交叉、指定时间段、月度趋势、桩号区间、面积统计、设备维度十个层次。

## 一、数据背景

### 表关系

- 病害表 `ai_problem`：一行是一条病害，`up_or_down` 记录病害所属上下行方向，`routes_id` 记录落点路线，`patrol_id` 指向巡检任务，`device_code` 记录采集设备编码。
- 巡检任务表 `ai_maintain_patrol`：一行是一次巡查，`task_number` 是任务编号，`patrol_number` 是巡查编号，`up_or_down` 记录任务本身登记的巡查方向。
- 路线台账 `basic_facilities_routes`：`id` 是路线主键，`full_name` 是路线全称。

### 病害上下行关键字段

- `up_or_down`：上下行，1 上行、2 下行，空字符串表示未标注方向，任务表同名字段是任务登记方向而非病害方向。
- `categories_type`：病害大类，0 路面病害、5 路基病害、10 沿路设施、15 交安事件。
- `damage_type`：病害细分代码，代码 0、5、10 三档，空值表示未识别，细分代码与字典两位编码不严格对应。
- `pile_distance`：解析桩号米数，单位为米，用于桩号区间分档。
- `area`：病害面积，单位为平方米。
- `device_code`：采集设备编码，病害表该列有值，与设备台账按设备编码关联。

### 全库最新事实

- 病害共 29230 条，其中上行 20752 条、下行 8436 条、未标注方向 42 条。
- 上行占比约七成一，下行占比约两成九。
- 巡检时间范围 2026-06-18 至 2026-11-04。
- 数据截至 2026-11-04 16:00，实查期间数据库持续写入，个别分组合计与全库总数存在个位数量级漂移，答案以本套题给出的实查数字为准。

### 必须避开的坑

#### 1. 病害上下行与任务上下行是两套口径

病害表的 `up_or_down` 是病害采集时落点的方向，任务表的 `up_or_down` 是任务登记的巡查方向。任务 XCBH202610310000 在任务表登记为 0 全部方向，其病害仍能分出上行 8106 处与下行 56 处，统计病害方向以病害表的 `up_or_down` 为准。

#### 2. 未标注方向单独列出

全库有 42 条病害 `up_or_down` 为空字符串，全部落在未知路线。按上下行统计时需单独列出，不能并入上行或下行，否则总数对不上。

#### 3. 病害大类合计必须等于总量

按 `categories_type` 分组后各组合计必须等于全库总量，可用于对账。四类合计 29230 与总量一致。

#### 4. 病害细分代码与字典编码不能对号入座

`damage_type` 只存 0、5、10 三档代码和空值，字典表 `ai_problem_base.problem_code` 是两位编码且不唯一，不能 JOIN 后按字典中文名报数，只能按代码报数。

#### 5. 11 月下行反超上行

月度数据里 6 月、7 月、10 月都是上行远多于下行，11 月下行 7901 处超过上行 3057 处，是本月新增下行采集导致的，按时间范围统计时以当月 `create_time` 过滤。

## 二、题目与标准答案

### 题1：全库病害按上下行的总数对比

**题目**

全库病害按上下行分别有多少处？上行和下行的占比各约多少？

**标准答案**

上行 20752 处，下行 8436 处，另有 42 处未标注方向。上行约占全库的七成一，下行约占两成九。

**统计口径**

- 按 `up_or_down` 分组，1 上行、2 下行，空值单独一组。
- 病害只统计 `del_flag=0`。
- 三组合计 29230 与全库总量一致。

**正确 SQL 口径**

```sql
SELECT up_or_down,
       COUNT(*) AS 病害数量
FROM ai_problem
WHERE del_flag = '0'
GROUP BY up_or_down
ORDER BY up_or_down;
```

### 题2：单次巡查任务按上下行的病害数量

**题目**

任务编号 XJJL202610310000 的这次巡查，检出的病害按上下行分别有多少处？

**标准答案**

上行 8106 处、下行 56 处，合计 8162 处。

**统计口径**

- 用 `task_number` 在巡检任务表定位任务，再按 `patrol_id` 关联病害表。
- 该任务在任务表登记的上下行为 0 全部方向，病害方向统计仍以病害表 `up_or_down` 为准。
- 病害只统计 `del_flag=0`。

**正确 SQL 口径**

```sql
SELECT pr.up_or_down,
       COUNT(*) AS 病害数量
FROM ai_problem pr
JOIN ai_maintain_patrol p ON p.id = pr.patrol_id
WHERE pr.del_flag = '0'
  AND p.del_flag = '0'
  AND p.task_number = 'XJJL202610310000'
GROUP BY pr.up_or_down;
```

### 题3：某条路线按上下行的病害数量

**题目**

S50长芷高速的病害按上下行分别有多少处？合计多少处？

**标准答案**

上行 11886 处、下行 1883 处，合计 13769 处。

**统计口径**

- 按病害落点路线 `routes_id` 关联路线台账，用 `full_name` 过滤 S50长芷高速。
- 病害只统计 `del_flag=0`，只统计已标注方向的记录。

**正确 SQL 口径**

```sql
SELECT pr.up_or_down,
       COUNT(*) AS 病害数量
FROM ai_problem pr
JOIN basic_facilities_routes r ON r.id = pr.routes_id
WHERE pr.del_flag = '0'
  AND r.full_name = 'S50长芷高速'
  AND pr.up_or_down IN ('1', '2')
GROUP BY pr.up_or_down;
```

### 题4：上下行与病害大类的交叉分布

**题目**

全库病害按上下行和路面病害、路基病害、沿路设施、交安事件四个大类交叉统计，各有多少处？

**标准答案**

路面病害上行 16887 处、下行 7420 处、未标注 27 处。
路基病害上行 5 处、下行 11 处。
沿路设施上行 2097 处、下行 586 处、未标注 13 处。
交安事件上行 1763 处、下行 419 处、未标注 2 处。

按大类合计路面病害 24334 处、路基病害 16 处、沿路设施 2696 处、交安事件 2184 处，四类合计 29230 处与全库总量一致。

**统计口径**

- 按 `categories_type` 和 `up_or_down` 双字段分组，0 路面病害、5 路基病害、10 沿路设施、15 交安事件。
- 大类合计与全库总数对账。

**正确 SQL 口径**

```sql
SELECT CASE pr.categories_type
         WHEN '0'  THEN '路面病害'
         WHEN '5'  THEN '路基病害'
         WHEN '10' THEN '沿路设施'
         WHEN '15' THEN '交安事件'
         ELSE '未分类' END AS 病害大类,
       pr.up_or_down,
       COUNT(*) AS 处数
FROM ai_problem pr
WHERE pr.del_flag = '0'
GROUP BY pr.categories_type, pr.up_or_down
ORDER BY 病害大类, pr.up_or_down;
```

### 题5：上下行与病害细分代码的交叉分布

**题目**

全库病害按上下行和病害细分代码交叉统计，代码 0、代码 5、代码 10 和未识别各有上行多少处、下行多少处？

**标准答案**

代码 0 上行 2151 处、下行 377 处。
代码 5 上行 7258 处、下行 4584 处。
代码 10 上行 7072 处、下行 2399 处。
未识别上行 4271 处、下行 1078 处、未标注方向 42 处。

**统计口径**

- 按 `damage_type` 和 `up_or_down` 双字段分组，空值归为未识别。
- 细分代码只能按代码报数，不能与字典两位编码对号入座。

**正确 SQL 口径**

```sql
SELECT COALESCE(pr.damage_type, '未识别') AS 细分代码,
       pr.up_or_down,
       COUNT(*) AS 处数
FROM ai_problem pr
WHERE pr.del_flag = '0'
GROUP BY pr.damage_type, pr.up_or_down
ORDER BY 细分代码, pr.up_or_down;
```

### 题6：指定时间段按上下行的病害数量

**题目**

2026 年 11 月检出的病害按上下行分别有多少处？

**标准答案**

上行 3057 处、下行 7901 处，合计 10958 处。本月下行数量反超上行，与 6 月、7 月、10 月的方向分布明显不同。

**统计口径**

- 按 `create_time` 过滤 2026-11-01 至 2026-12-01，再按 `up_or_down` 分组。
- 11 月数据截至快照时刻，后续写入以实时库为准。

**正确 SQL 口径**

```sql
SELECT up_or_down,
       COUNT(*) AS 病害数量
FROM ai_problem
WHERE del_flag = '0'
  AND create_time >= '2026-11-01 00:00:00'
  AND create_time <  '2026-12-01 00:00:00'
GROUP BY up_or_down
ORDER BY up_or_down;
```

### 题7：各月病害按上下行的数量趋势

**题目**

2026 年 6 月、7 月、10 月、11 月每个月检出的病害按上下行分别有多少处？整体呈什么趋势？

**标准答案**

2026 年 6 月上行 289 处、下行 17 处、未标注 17 处。
2026 年 7 月上行 1354 处、未标注 25 处，当月无下行记录。
2026 年 10 月上行 16052 处、下行 524 处。
2026 年 11 月上行 3057 处、下行 7902 处。

整体趋势是 10 月达到上行峰值 16052 处，11 月下行爆发到 7902 处反超上行，采集重心从上行转向下行。

**统计口径**

- 按 `DATE_FORMAT(create_time, '%Y-%m')` 和 `up_or_down` 双字段分组。
- 各月合计与全库总量对账，差值来自快照后新写入的数据。

**正确 SQL 口径**

```sql
SELECT DATE_FORMAT(create_time, '%Y-%m') AS 月份,
       up_or_down,
       COUNT(*) AS 病害数量
FROM ai_problem
WHERE del_flag = '0'
GROUP BY 月份, up_or_down
ORDER BY 月份, up_or_down;
```

### 题8：按桩号区间的上下行病害数量

**题目**

全库病害按桩号区间分档，桩号 1000 公里及以上、500 至 1000 公里、100 至 500 公里、100 公里以内四档，上行和下行分别有多少处？

**标准答案**

上行桩号 1000 公里及以上 6048 处、500 至 1000 公里 2 处、100 至 500 公里 2588 处、100 公里以内 12114 处，合计 20752 处。
下行桩号 1000 公里及以上 2005 处、500 至 1000 公里 0 处、100 至 500 公里 5752 处、100 公里以内 688 处，合计 8445 处。

**统计口径**

- `pile_distance` 单位为米，1000 公里即 1000000 米，分档边界含下限不含上限。
- 上行全部记录都有桩号，未标注方向 42 条无桩号不参与分档。

**正确 SQL 口径**

```sql
SELECT up_or_down,
       CASE
         WHEN pile_distance >= 1000000 THEN '1000公里及以上'
         WHEN pile_distance >= 500000  THEN '500至1000公里'
         WHEN pile_distance >= 100000  THEN '100至500公里'
         ELSE '100公里以内' END AS 桩号区间,
       COUNT(*) AS 处数
FROM ai_problem
WHERE del_flag = '0'
  AND up_or_down IN ('1', '2')
GROUP BY up_or_down, 桩号区间
ORDER BY up_or_down, 桩号区间;
```

### 题9：按上下行的病害面积合计与平均面积

**题目**

全库病害按上下行统计面积，上行和下行的面积合计、平均面积各是多少？

**标准答案**

上行 20752 处，面积合计 592549.28 平方米，平均每处 28.55 平方米。
下行 8447 处，面积合计 234344.36 平方米，平均每处 27.74 平方米。
未标注方向 42 条面积为空，不参与统计。

**统计口径**

- 按 `up_or_down` 分组，对 `area` 求和、求平均。
- 未标注方向病害面积为空，统计时自然剔除，不影响上下行两组。

**正确 SQL 口径**

```sql
SELECT up_or_down,
       COUNT(*) AS 病害数量,
       ROUND(SUM(area), 2) AS 面积合计,
       ROUND(AVG(area), 2) AS 平均面积
FROM ai_problem
WHERE del_flag = '0'
GROUP BY up_or_down
ORDER BY up_or_down;
```
