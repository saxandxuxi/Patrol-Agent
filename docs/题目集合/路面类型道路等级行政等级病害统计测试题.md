# 按路面类型 / 道路等级 / 行政等级区分病害数量 测试题（3 道）

所有答案均为 2026-10-20 通过项目只读数据库实查得出，口径为未删除记录 `del_flag=0`。

## 一、数据背景

### 三个维度字段都在路段表，不在病害表

路面类型、道路技术等级、行政等级三个维度都存在于路段表 `basic_facilities_sections`，病害表 `ai_problem` 本身没有这三个字段。

病害必须通过 `ai_problem.sections_id = basic_facilities_sections.id` 关联路段表才能取到这些维度。这是本组题的核心考点：只认单表会回答 "病害表没有路面类型字段"。

### 字段与枚举



| 维度     | 字段             | 枚举含义                                              |
| ------ | -------------- | ------------------------------------------------- |
| 路面类型   | `surface_type` | 11 沥青混凝土、12 水泥混凝土、21 沥青贯入式、22 沥青碎石、31 砂石路面、36 无路面 |
| 道路技术等级 | `tech_grade`   | 0 高速公路、1 一级公路、2 二级公路、3 三级公路、4 四级公路、5 等外公路         |
| 行政等级   | `route_level`  | 0 国道、1 省道、2 县道、3 乡道、4 村道                          |

### 病害实查分布

病害共 1702 条，关联到三条路线，JOIN 路段表不放大行数。



| 路线          | 路面类型  | 技术等级 | 行政等级 | 病害数 |
| ----------- | ----- | ---- | ---- | --- |
| 宝安大道西乡段     | 沥青混凝土 | 一级公路 | 国道   | 911 |
| 宝安中心 -- 恒明珠 | 沥青混凝土 | 二级公路 | 国道   | 749 |
| 未知路线        | 沥青混凝土 | 未填   | 未填   | 42  |

按维度汇总：



* 路面类型：沥青混凝土 1702 条；水泥混凝土 0 条。

* 技术等级：一级公路 911 条，二级公路 749 条，未填技术等级 42 条。

* 行政等级：国道 1660 条，未填行政等级 42 条。

### 易错点



1. 路段表共 5840 个路段，其中 5680 个是水泥混凝土路面，但病害全部来自沥青混凝土路面。不能因为水泥路段多就认为病害也多，病害数必须以实际关联结果为准。

2. 统计前必须确认病害表 `sections_id` 与路段表 `id` 是多对一关系，JOIN 不放大。实测 1702 条病害 JOIN 后仍为 1702 条，且无匹配不到路段的记录。

3. 有 42 条病害所在路段未填技术等级和行政等级，分组统计时应如实呈现为未填或未知，不能丢弃也不能并入其他等级。

## 二、题目与标准答案

### 题 1：按路面类型区分（含零值对照）

**题目**

沥青混凝土路面和水泥混凝土路面上分别检出了多少处病害？

**标准答案**



* 沥青混凝土路面：1702 处。

* 水泥混凝土路面：0 处。

**考点**



* 用 `surface_type` 筛选，11 为沥青混凝土、12 为水泥混凝土。

* 病害 JOIN 路段表后按路面类型分组。

* 水泥混凝土路面虽有 5680 个路段，但实际检出病害为 0，系统必须如实回答 0，不能凭路段数量推测。

**正确 SQL 口径**



```
SELECT s.surface\_type, COUNT(DISTINCT p.id) AS 病害数量

FROM ai\_problem p

JOIN basic\_facilities\_sections s ON s.id = p.sections\_id

WHERE p.del\_flag = 0

GROUP BY s.surface\_type;
```

### 题 2：按道路技术等级区分

**题目**

按公路技术等级统计，一级公路和二级公路上分别检出了多少处病害？

**标准答案**



* 一级公路：911 处。

* 二级公路：749 处。

* 另有 42 处病害所在路段未填技术等级。

**考点**



* 用 `tech_grade` 分组，1 为一级公路、2 为二级公路。

* 911 处来自宝安大道西乡段，749 处来自宝安中心 -- 恒明珠段。

* 未填等级的 42 条不能丢弃，应在结果中说明。

**正确 SQL 口径**



```
SELECT s.tech\_grade, COUNT(DISTINCT p.id) AS 病害数量

FROM ai\_problem p

JOIN basic\_facilities\_sections s ON s.id = p.sections\_id

WHERE p.del\_flag = 0

GROUP BY s.tech\_grade

ORDER BY 病害数量 DESC;
```

### 题 3：按行政等级区分

**题目**

国道上检出的病害一共有多少处？

**标准答案**

1660 处。其中宝安大道西乡段 911 处、宝安中心 -- 恒明珠段 749 处，两条路段行政等级均为国道。

另有 42 处病害所在路段未填行政等级，不计入国道。

**考点**



* 用 `route_level` 筛选，0 为国道。

* 国道数量是两条路段病害数之和，不是单一某条路线。

* 未填行政等级的 42 条不能并入国道。

**正确 SQL 口径**



```
SELECT COUNT(DISTINCT p.id) AS 国道病害数量

FROM ai\_problem p

JOIN basic\_facilities\_sections s ON s.id = p.sections\_id

WHERE p.del\_flag = 0

&#x20; AND s.route\_level = '0';
```

## 三、验收检查项



1. 三道题都必须 JOIN 路段表取维度，不能回答 "病害表没有路面类型或等级字段"。

2. 题 1 答案为沥青 1702、水泥 0，水泥结果必须是 0，不能因路段数量大而报错。

3. 题 2 答案为一级 911、二级 749，并体现未填的 42 条。

4. 题 3 答案为 1660，未填等级的 42 条不能计入国道。

5. 所有统计均使用 `COUNT(DISTINCT p.id)`，并过滤 `del_flag=0`。

6. 各维度分组后的数量之和应等于病害总数 1702，可用于自证。
