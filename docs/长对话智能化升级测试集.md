# 长对话智能化升级测试集

> 不需要给答案，用来测试长对话补全、拆分、综合分析的能力。
> 贴近真实企业巡查场景，覆盖各种长对话情况。

---

## 长对话1：从数据查询 → 下钻明细 → 纠正条件 → 综合分析

**测试点：条件继承、加新条件、纠正条件、换输出形式、数据+知识综合分析**

```
R1：西乡段和恒明珠段，7月份各发现了多少处病害？

R2：西乡段的，按上下行分开统计一下

R3：其中面积大于5平方米的有多少？

R4：把这些大面积病害的明细调出来

R5：不对，我是说面积大于10平方米的，不是5平方米的

R6：恒明珠段也按这个条件筛一下，对比一下两条路的大面积病害情况

R7：结合养护规范分析一下，这两条路哪个的养护压力更大？重点应该先处理哪条路？
```

**测试目标：**
- R2：继承路线+时间，加新条件（上下行分组）
- R3：继承前面所有条件，加新过滤（面积>5㎡）
- R4：继承所有过滤条件，换输出形式（计数→明细）
- R5：替换过滤条件（5㎡→10㎡），其他条件继承
- R6：换查询对象（西乡段→恒明珠），保留其他条件
- R7：数据+知识综合分析（不是分别罗列，要给结论）

---

## 长对话2：从病害类型统计 → 分档对比 → 分布分析 → 原因分析

**测试点：换查询对象、分档对比、换分组维度、多步推理、原因分析**

```
R1：西乡段7月份采集的病害里，主要是哪几种类型？各有多少？

R2：恒明珠段呢？对比一下两条路的主要病害类型

R3：西乡段的泛油病害，是集中在一头还是两头都有？

R4：那新长出来的多还是早就有的多？

R5：为什么泛油病害会集中在那个位置？跟什么有关？

R6：这些高发路段的养护优先级怎么排？哪几个桩号段要优先处理？
```

**测试目标：**
- R2：换路线，保留其他条件
- R3：换查询维度（类型→空间分布），保留路线+病害类型
- R4：换分档维度（空间→时间新旧），保留路线+病害类型
- R5：原因分析（不是查数据，是结合数据+规范做推理）
- R6：多步推理（先找出高发路段，再排优先级）

---

## 长对话3：从巡检任务 → 病害发现 → 图片查看 → 综合评估

**测试点：换查询对象、加过滤条件、换输出形式、纠正条件、数据+知识综合分析**

```
R1：7月份西乡段一共巡检了几次？每次巡检发现了多少处病害？

R2：哪次巡检发现的病害最多？

R3：把那次巡检的病害明细调出来

R4：不对，我要的是病害最多的那次，不是最后一次

R5：那次巡检的病害有照片吗？给我看看前10张

R6：GPS轨迹也一起看一下，确认一下巡检路线有没有覆盖全

R7：结合这些数据评估一下，西乡段7月份的巡检质量怎么样？有没有漏检的风险？
```

**测试目标：**
- R2：从所有次→找最多的那次（条件缩小）
- R3：换输出形式（统计→明细），继承"病害最多的那次"
- R4：纠正条件（我不是要最后一次，我要最多的那次）
- R5：换查询对象（病害明细→病害图片），继承前面的条件
- R6：再加一个查询对象（GPS轨迹），继承所有条件
- R7：综合分析（巡检次数+病害数量+覆盖率，判断巡检质量）

## 长对话4：从片区对比 → 密度分析 → 原因分析 → 养护建议

**测试点：管养维度、分档对比、原因分析、多步推理、综合建议**

```
R1：我们管的这几条路，哪个路段的病害密度最高？排个序

R2：密度最高的那条路，病害类型主要是什么？

R3：它比其他路高这么多，是因为巡检频繁，还是真的病害多？

R4：按养护规范，这种密度的路段算什么等级？需要多久养护一次？

R5：给个养护建议吧，下个月的养护计划怎么排？钱应该优先投在哪条路？
```

**测试目标：**
- R2：从整体密度→细化到病害类型（下钻）
- R3：原因分析（两个假设：巡检频繁 vs 真病害多，需要查两次巡检次数和实际病害数）
- R4：数据+知识结合（密度数值 + 养护规范等级标准）
- R5：综合建议（基于前面所有分析，给养护计划建议）

---

## 测试说明

| 长对话 | 主要测试什么 |
|--------|------------|
| 对话1 | 条件继承/替换/加新/去掉、纠正、换输出形式、综合分析 |
| 对话2 | 换查询对象、分档对比、原因分析、多步推理 |
| 对话3 | 换查询对象（病害→图片→GPS）、纠正条件、巡检质量评估 |
| 对话4 | 片区对比、密度分析、原因假设、养护建议 |

**所有对话都要求：**
1. 每一轮都要正确继承前面的条件
2. 该拆的拆，不该拆的不拆
3. 最后一轮的综合分析要真的"分析"，不是把数据和规范分别念一遍
