# 小白级教程：10.168.210.78 上各数据库的密码怎么查出来

> 前提：已经 SSH 登录进服务器（`ssh root@10.168.210.78`）
> 原理：**密码一定写在某个配置文件里**（或 Docker 环境变量里），找到文件就找到密码

---

## 第 0 步：先判断服务是"Docker 装的"还是"直接装的"（最重要的一步）

执行：
```bash
docker ps
```

**情况 A：有输出**（列出一堆容器）→ 服务是 Docker 部署的，密码**优先在容器环境变量里**，看第 1 节；
**情况 B：提示 command not found** → 服务器没装 Docker，服务是原生安装，密码在配置文件里，直接看第 2 节起。

---

## 第 1 节：Docker 部署时，密码怎么查（通用方法）

```bash
# 1. 先看所有容器名
docker ps

# 2. 每个容器挨个查环境变量（把 容器名 换成上面看到的名字，如 mysql、rabbitmq）
docker inspect 容器名 | grep -i "pass\|user"

# 3. 如果环境变量里没有，看容器里挂载的配置文件
docker exec -it 容器名 cat /etc/xxx.conf
```

> 示例：容器叫 `mysql`，就执行 `docker inspect mysql | grep -i pass`，输出里的 `MYSQL_ROOT_PASSWORD=xxx` 就是 root 密码。

---

## 第 2 节：MySQL（3307）密码

```bash
# 配置文件在这里（依次试）
cat /etc/my.cnf
cat /etc/my.cnf.d/*.cnf
```

**找什么**：配置文件里 `[client]` 或 `[mysqld]` 段下面的 `password=xxx`（有的叫 `user=` 和 `password=`）。

**如果配置里没有**（很常见，密码在别处）：
```bash
# 方法1：看初始化记录（如果系统记录过）
grep -i "password" /var/log/mysqld.log | tail -5

# 方法2：本机免密直接进，然后自己改一个（改完记得记下来）
mysql -uroot
ALTER USER 'root'@'localhost' IDENTIFIED BY '你自己设的密码';
```

---

## 第 3 节：PostgreSQL（5436）密码

PostgreSQL 的密码**不在配置文件里明文存放**，用"免密进入→自己设"的方式：

```bash
# 1. 先看认证方式（有 peer 或 trust = 本机免密）
cat /var/lib/pgsql/data/pg_hba.conf | head -20

# 2. 免密进入（sudo 可能要你的登录密码）
sudo -u postgres psql

# 3. 进去后改密码
ALTER USER postgres WITH PASSWORD '你自己设的密码';
\q
```

> 如果你能免密进去，密码就掌握在你手里了，不需要找回旧的。

---

## 第 4 节：Redis（6376）密码

```bash
# 配置文件在这里
cat /etc/redis.conf
# 或
cat /etc/redis/redis.conf
```

**找什么**：搜到 `requirepass 密码` 那一行，`requirepass` 后面就是密码。

**没有 requirepass 这一行** = Redis 没设密码，直接连就行。

---

## 第 5 节：EMQX（6883、23083）密码

```bash
# 1. 看主配置
cat /etc/emqx/emqx.conf | grep -i "password"

# 2. 看控制台管理员账号（这是网页登录用的）
/usr/bin/emqx ctl admins list
# 或
/usr/bin/emqx ctl admins

# 3. 默认没改过的话：admin / public
```

> EMQX 还有一类是"设备连接密码"（MQTT 鉴权），存在它的内置数据库或配置的认证文件里，这个一般问业务方，命令行查不到。

---

## 第 6 节：RabbitMQ（15672、5672）密码

```bash
# 方法1：命令行直接看用户（需要 rabbitmqctl 命令）
rabbitmqctl list_users

# 方法2：配置文件
cat /etc/rabbitmq/rabbitmq.conf | grep -i "pass"
cat /etc/rabbitmq/advanced.config

# 方法3：如果是 Docker，环境变量里有
docker inspect 容器名 | grep -i "RABBITMQ_DEFAULT_PASS"
```

> `rabbitmqctl list_users` 只显示用户名（密码不回显），但能看到有哪些账号；密码若配置里没有，直接改：
> `rabbitmqctl change_password 用户名 新密码`

---

## 第 7 节：Nacos（6648、6748）密码

```bash
# 配置文件在这里
cat /usr/local/nacos/conf/application.properties
```

**找什么**（两个密码都在这个文件里）：
1. **控制台登录密码**：默认 `nacos / nacos`（没改过就是这个）；
2. **它连的数据库密码**（Nacos 把配置存 MySQL，这里会写 MySQL 的账号密码，能白捡一组）：
```
spring.datasource.username=xxx
spring.datasource.password=xxx
```

---

## 第 8 节：Elasticsearch（19200、9200）密码

```bash
# 看有没有开认证
cat /etc/elasticsearch/elasticsearch.yml | grep -i "xpack.security"
```

- 显示 `xpack.security.enabled: false` 或**没有这一行** → **没密码**，直接 curl 就能访问；
- 显示 `true` → 开了认证，用户是 `elastic`，密码没法从文件找回，重置：
```bash
cd /usr/share/elasticsearch/bin
./elasticsearch-setup-passwords interactive
```

---

## 第 9 节：elasticsearch-head（19100）

**没有密码**。它是网页工具，浏览器打开 `http://10.168.210.78:19100` 直接用。

---

## 第 10 节：SeaweedFS（8899、23646）

**一般没有密码**（内网对象存储）。验证：`curl http://127.0.0.1:8899/cluster/status` 有返回就正常。

---

## 第 11 节：mediamtx（18888、18322）

**一般没有密码**。看配置确认：`cat /etc/mediamtx/mediamtx.yml`，有 `auth` 段才有密码。

---

## 万能兜底命令（上面都找不到时用）

```bash
# 全盘搜密码关键字（可能跑一会，耐心等）
grep -rn "password\|passwd\|PASSWORD\|requirepass" /etc /opt /usr/local /home 2>/dev/null | grep -v "^Binary"

# 找所有可能的配置文件
find / -name "*.conf" -o -name "*.properties" -o -name "*.yml" 2>/dev/null | grep -v "/proc/\|/sys/" | head -50
```
