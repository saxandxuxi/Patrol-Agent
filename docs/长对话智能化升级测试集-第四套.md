# 长对话智能化升级测试集-第四套（新字段覆盖版）

> 第四套测试集，专门覆盖之前没问到过的字段。
> 之前三套都围绕"病害数量/类型/密度"这几个老字段，这套把收藏、关注、转工单、病害来源、路格、经纬度这些新字段都用上。

---

## 一、单查询测试题（20道）

### 1. 收藏与关注类

1. 西乡段收藏的病害有多少处？
2. 全库有多少处病害被标记为"关注病害"？
3. 西乡段收藏的病害都是什么类型？
4. 哪些病害是收藏了但还没转工单的？

### 2. 工单状态类

5. 西乡段已转工单的病害有多少处？
6. 全库待转工单的病害有多少？占全部的比例是多少？
7. 西乡段忽略的病害有多少处？都是什么类型？
8. 已转工单和待转工单的比例是多少？

### 3. 病害来源类

9. 西乡段车辆巡检发现的病害有多少？人工巡检的有多少？
10. 全库手动新增的病害有多少处？
11. 西乡段路长转养护的病害有多少？
12. 哪种来源的病害平均面积最大？

### 4. 路格与定位类

13. 西乡段哪个路格的病害最多？
14. 全库有多少个不同的路格？
15. 西乡段K0+100附近（经纬度坐标点）有多少处病害？
16. 经纬度显示，病害主要分布在西乡段的哪一侧？

### 5. 质量与风险类

17. 西乡段历史损坏程度严重的病害有多少处？
18. 全库关注病害里，面积最大的是哪条？
19. 西乡段没绑定巡查任务的病害有多少？
20. 哪个设备采集的病害最多？

## 二、长对话测试集（4组）

### 对话13：收藏病害 → 分析风险 → 养护优先级

**测试点：收藏字段、风险分析、养护优先级**

```
R1：西乡段收藏的病害有多少处？

R2：这些收藏的病害主要是什么类型？面积大不大？

R3：按面积从大到小排前5条，都在哪个桩号？

R4：这几条大面积病害，有没有转工单？没转的话为什么还没处理？

R5：这些收藏的病害，养护优先级怎么排？哪几条最紧急？
```

**测试目标：**
- R1：查询收藏字段
- R2：下钻到类型+面积
- R3：再下钻到具体桩号
- R4：关联工单状态
- R5：从数据 → 养护决策

---

### 对话14：工单状态盘点 → 找漏处理 → 催办建议

**测试点：工单状态字段、漏处理识别、催办建议**

```
R1：西乡段现在一共有多少处病害？其中待转工单的有多少？

R2：待转工单的这些病害，都是什么类型？集中在哪一段？

R3：待转工单的病害里，面积最大的有哪几条？

R4：这些待转的病害，已经放了多久了？有没有超过7天还没处理的？

R5：如果要催办，应该优先催哪些？给个清单。
```

**测试目标：**
- R1：工单状态分组统计
- R2：下钻到类型+路段
- R3：再下钻到大面积的
- R4：关联时间，找逾期的
- R5：从数据 → 催办清单

---

### 对话15：病害来源对比 → 巡检质量分析

**测试点：病害来源字段、巡检质量分析**

```
R1：西乡段7月份的病害，都是哪些来源发现的？各有多少？

R2：车辆巡检和人工巡检发现的病害，类型分布有什么不一样？

R3：为什么人工巡检发现的病害，平均面积比车辆巡检的大？

R4：手动新增的病害有多少？是谁新增的？

R5：从来源数据看，人工巡检和车辆巡检哪个效果更好？
```

**测试目标：**
- R1：按来源分组统计
- R2：跨维度对比（来源×类型）
- R3：原因分析
- R4：下钻到具体来源
- R5：质量评估建议

---

### 对话16：路格分布 → 定位重灾区

**测试点：路格字段、经纬度定位、空间分布**

```
R1：西乡段的病害，按路格分哪个路格最多？

R2：病害最多的那个路格，大概在什么位置？经纬度显示它在西乡段的哪一段？

R3：这个路格为什么病害这么多？是路面问题还是交通流量大？

R4：这个路格附近（半径50米内）还有没有其他病害？

R5：如果要安排一次集中排查，应该从哪条路开始查？
```

**测试目标：**
- R1：按路格分组统计
- R2：关联经纬度定位
- R3：空间定位 → 原因分析
- R4：空间邻近查询
- R5：从数据 → 现场排查建议

## 涉及的新字段（之前没怎么用过的）

| 字段名 | 中文意思 | 怎么问 |
|--------|---------|--------|
| collect | 收藏（0否1是） | 收藏的病害有多少？ |
| track_problem | 关注病害 | 标记为关注的有多少？ |
| problem_status | 病害状态（待转/已转/忽略） | 待转工单的有多少？ |
| problem_source | 病害来源（手动/车辆/人工） | 车辆巡检发现的有多少？ |
| mission_flag | 是否绑定巡查任务 | 没绑定任务的有多少？ |
| luge_name | 路格 | 哪个路格病害最多？ |
| lng/lat | 经纬度 | 附近有多少病害？ |
| history_damage_interval | 历史损坏程度 | 严重的病害有多少？ |
| patrol_id | 巡查任务id | 那次巡检的明细？ |
| vehicle_id | 车辆id | 哪辆车采的？ |
| inspection_user_id | 巡检用户id | 谁发现的？ |

## 检查点

| 检查项 | 为什么要查 |
|--------|-----------|
| 字段翻译对不对 | 收藏/关注/工单状态这些字段，能不能正确翻译成中文 |
| 分组维度对不对 | 按来源/按状态/按路格分组，有没有漏组 |
| 下钻有没有断 | 从总数 → 类型 → 具体桩号，有没有断链 |
| 有没有用对过滤条件 | collect=1 而不是 collect='1'，状态值对不对 |
| 建议有没有落地 | 养护优先级/催办清单，有没有说具体 |
