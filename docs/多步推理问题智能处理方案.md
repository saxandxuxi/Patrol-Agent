# 多步推理问题的智能处理方案

> 场景："西乡段的路况好不好？不好的话该如何养护，重点养护哪些路段？"
> 特点：有依赖关系，不是拆成几个子任务并行跑，而是一步一步来，每一步根据结果决定下一步。

---

## 一、这个问题难在哪？

```
西乡段的路况，好不好？不好的话该如何养护，重点养护哪些路段？
```

**这句话里有三层：**
1. **判断：** 路况好不好？（先查数据）
2. **条件分支：** 如果不好，该怎么养护？（查规范）
3. **具体落地：** 重点养护哪些路段？（结合数据+规范）

**关键是：这三步是有依赖的！**
- 必须先知道"好不好"，才知道要不要查规范
- 必须先知道"哪些路段病害多"，再结合规范判断"哪些要重点养护"

不是拆成几个子任务并行跑就行的。

---

## 二、智能的处理流程

### 第一步：理解用户问题的结构

用户要的是：
1. 先判断路况好不好
2. 如果不好，给养护建议
3. 还要指出具体哪些路段要重点养护

**不是一个简单的SQL查询，是一个完整的分析过程。**

---

### 第二步：先查数据，判断路况好不好

**查什么？**
- 总病害数量
- 病害密度（处/公里）
- 病害类型分布
- 平均面积
- 各路段的病害分布

**判断逻辑（给LLM看）：**
> 基于以下数据，判断西乡段的路况好不好：
> - 病害总数：911处
> - 病害密度：178.6处/km
> - 平均面积：61.7㎡
> - ...

**输出：**
> 西乡段路况**比较严重**：
> - 病害密度高达178.6处/km，远高于一般水平
> - 单处平均面积61.7㎡，说明病害规模不小
> - 未识别类型占41.4%，说明AI识别也不准

---

### 第三步：如果不好，再查养护规范

**判断：** 路况不好 → 需要查养护规范

**查什么？**
- 路面病害养护标准
- 什么情况下需要重点养护
- 不同类型病害的处理优先级

**给LLM看：**
> 根据养护规范：
> - 病害密度超过100处/km 属于"严重"等级，需要优先处理
> - 大面积病害（>50㎡）优先级高于小面积
> - 未识别病害需要先人工复核，再处理

---

### 第四步：综合分析，给出养护建议+重点路段

**把数据和规范都给LLM：**

```
数据：
  - 总病害：911处
  - 密度：178.6处/km（严重）
  - 各路段分布：K0-K1有200处，K1-K2有180处，K2-K3有150处...

规范：
  - 密度>100处/km 算严重，需要优先处理
  - 大面积病害优先级更高
  - 未识别病害要先人工复核

请综合以上信息，给出：
1. 西乡段路况总体判断
2. 养护优先级建议
3. 重点养护路段（哪几个桩号段）
```

**LLM输出：**
> **总体判断：** 西乡段路况较差，病害密度178.6处/km，远超"严重"标准（100处/km）。
>
> **养护建议：**
> 1. 优先处理大面积病害（>50㎡的有XX处）
> 2. 先人工复核未识别的377处病害，确认类型
> 3. 泛油属于轻微病害，可以延后处理
>
> **重点养护路段：**
> - K0+000~K0+500：病害最密集，有200处，优先处理
> - K2+000~K2+500：大面积病害集中，需要优先处置

---

## 三、现在的系统为什么处理不了？

**现在的做法：**
```
用户问题 → 拆分器拆成几个子任务 → 并行执行 → 拼结果
```

**问题：**
1. **没有"判断"这一步：** 不知道路况好不好，不知道要不要查规范
2. **没有依赖关系：** 所有子任务并行跑，不知道哪个要先做
3. **没有"综合分析"：** 只是把子任务结果拼起来，不会根据数据做推理

---

## 四、怎么改？

### 1. 加"多步推理"模式

在拆分器里，识别这种有依赖关系的问题：
- 先做A，根据A的结果决定做不做B
- 最后C要结合A和B的结果

### 2. 执行顺序是动态的

不是固定先跑哪个子任务，而是：
1. 先跑第一步（查数据判断好不好）
2. 根据结果决定：要不要查规范？
3. 再跑第三步（综合分析）

### 3. 最后一步是"综合分析"

把前面所有步骤的结果，都给最后一步的LLM，让它综合推理。

---

## 五、这就是智能体和流水线的区别

| 流水线（现在） | 智能体（改完） |
|-------------|-------------|
| 先拆好所有子任务 | 一步一步来，根据结果决定下一步 |
| 所有子任务并行跑 | 有依赖的串行执行 |
| 最后拼结果 | 最后综合分析，给出结论 |
| 机械执行 | 有判断、有推理 |

**核心区别：**
- 流水线：你说什么我做什么，一步一步按流程走
- 智能体：我理解你要什么，自己想办法分步完成

---

## 六、优先级

| 优先级 | 改动 | 效果 |
|--------|------|------|
| P0 | 加"先查数据再判断"的模式 | 能回答"好不好/严不严重" |
| P1 | 加"根据结果决定下一步" | 条件分支（不好才查规范） |
| P1 | 加最后一步综合分析 | 结合数据+规范给出结论 |
| P2 | 识别"重点养护哪些路段" | 能指出具体路段 |
