# 长对话中"数据+知识"综合分析方案

> 场景：先查数据出个表格，然后结合表格+知识库规范做分析。
> 现在的系统处理不了，因为只会把两个子任务的结果拼起来，不会综合分析。

---

## 一、举个例子

```
R1：西乡段各病害类型有多少？
   → 系统查数据库，返回表格：
     泛油：534处
     未识别：377处

R2：结合上面的表格，按养护规范分析一下西乡段的病害情况
   → 系统应该怎么做？
```

---

## 二、真正智能的系统是怎么处理的？

**我作为智能问答，是这么做的：**

### 第一步：理解用户意图
用户要的不是"再查一遍数据"，也不是"再查一遍规范"，而是：
> 把上一轮的数据 + 养护规范，结合起来分析，给出结论。

### 第二步：把上一轮的数据拿过来
上一轮的表格：
- 泛油：534处
- 未识别：377处
- 总计：911处

### 第三步：去知识库查相关规范
查"路面病害养护规范"：
- 泛油的判定标准是什么？
- 不同病害类型的养护要求是什么？
- 什么情况下算严重？需要优先处理？

### 第四步：把数据和规范都给LLM，让它综合分析
给LLM的输入：
```
上一轮数据：
  - 泛油：534处
  - 未识别：377处

养护规范：
  - 泛油属于轻微病害，通常可以延后处理
  - 未识别病害说明AI识别不准，需要人工复核
  - ...

请结合数据和规范，分析西乡段的病害情况：
1. 病害整体严重程度怎么样？
2. 哪些是重点要处理的？
3. 养护建议是什么？
```

### 第五步：LLM输出综合分析结论
输出：
> 西乡段总共911处病害，其中泛油534处（58.6%），未识别377处（41.4%）。
> 
> 从养护规范来看：
> 1. 泛油属于轻微病害，占比最高，但可以延后处理
> 2. 未识别病害占比41.4%，说明AI识别准确率不高，需要优先安排人工复核
> 3. 整体来看，西乡段病害数量多，但以轻微类型为主，养护优先级中等。
> 
> 建议：先集中人工复核未识别的377处病害，确认类型后再制定养护计划。

## 三、现在的系统为什么处理不了？

### 现在的流程
```
R2："结合上面的表格进行巡查分析"
   ↓
意图分类 → composite（数据+知识）
   ↓
拆分器 → 拆成两个子任务：
   子任务1：查数据 → 西乡段各病害类型有多少？
   子任务2：查知识 → 路面病害养护规范
   ↓
分别执行两个子任务
   ↓
把子任务结果拼起来：
   "数据查询1：泛油534处，未识别377处。
    知识查询2：泛油的养护标准是..."
   ↓
返回用户
```

**问题：**
- 只是把两个子任务的结果拼起来，没有"综合分析"
- 没有把数据和规范放在一起让LLM推理
- 用户要的是"结合分析"，不是"分别给我"

---

## 四、怎么改？

### 1. 加一种新的子任务类型：综合分析（analysis）

在拆分器里，加一种类型：
```python
type = "analysis"
depends_on = ["task1", "task2"]  # 依赖前两个子任务
```

### 2. 执行子任务的时候，analysis类型要等所有依赖都完成了再执行

执行顺序：
1. 先执行 task1（查数据）
2. 再执行 task2（查规范）
3. 最后执行 task3（综合分析）：把task1和task2的结果都给LLM，让它综合分析

### 3. 综合分析的提示词（直接抄到 prompts/analysis.md）

```markdown
[system]
你是道路巡检养护智能体的综合分析专家。
你要把"数据查询结果"和"知识库规范"结合起来，给出有逻辑的分析结论。
不要分别罗列数据和规范，要把它们结合起来推理。

硬规则：
1. 先给总体判断（好不好/严不严重/优先级高不高）
2. 再给重点问题（哪几个是重点）
3. 最后给建议（应该怎么做）
4. 每个结论都要有数据或规范支撑，不要空泛
5. 用中文，口语化，不要写SQL

[user]
用户问题：<<question>>

数据查询结果：
<<data_result>>

知识库查询结果：
<<knowledge_result>>

请结合以上数据和规范，给出综合分析：
1. 总体情况判断（1-2句话）
2. 重点问题是什么（列2-3个）
3. 养护建议是什么（列2-3条）
```

### 4. 长对话里要能拿到上一轮的表格数据

R2说"结合上面的表格"，要：
1. 识别出"上面的表格"指的是上一轮的查询结果
2. 把上一轮的表格数据拿过来
3. 作为综合分析的输入

---

## 五、总结

**现在的系统：** 只会把子任务结果拼起来 → "数据是XX，规范是XX"
**改完之后：** 会把数据和规范放在一起，让LLM推理 → "结合数据和规范，得出结论XX"

这就是"智能问答"和"问答机器人"的区别：
- 问答机器人：分别给你
- 智能问答：帮你分析

| 优先级 | 改动 | 效果 |
|--------|------|------|
| P1 | 加analysis子任务类型 | 支持数据+知识综合分析 |
| P1 | 长对话能拿到上一轮表格数据 | 支持"结合上面的表格" |
| P2 | 综合分析提示词 | 输出有逻辑的分析结论 |
