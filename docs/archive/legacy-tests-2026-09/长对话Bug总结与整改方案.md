# 长对话Bug总结与整改方案

> 基于用户实测的长对话，总结4个核心bug。
> 这些bug都是"长对话补全不够智能"导致的。

---

## Bug 1：图片查询找不到图

### 现象
```
R1：西乡段7月30日有多少处泛油？ → 185处
R2：能看看这些病害的照片吗？ → 没有找到相关病害图片
```

### 问题
- 继承了条件（西乡段、7月30日、泛油）✅
- 但为什么找不到图片？是真的没有，还是SQL写错了？
- 应该继承所有过滤条件，去查这些病害的problem_url

---

## Bug 2：拆分器乱拆，不该拆的拆了

### 现象
```
R3：GPS轨迹也一起看？ → 拆成了2个子问题：
  子问题1：185条病害明细
  子问题2：GPS轨迹（未查到）
```

### 问题
- 用户就是要GPS轨迹，不需要拆成两个子问题
- 应该：继承所有过滤条件（西乡段、7月30日、泛油），只换查询对象（从病害明细→GPS轨迹）
- 拆成两个子问题是多余的，而且第一个子问题是重复查询

---

## Bug 3：过滤条件丢失

### 现象
```
R1：全库泛油里面积正好7.52㎡的有几处？ → 17处
R2：其中西乡段的有多少？ → 12处
R3：把西乡段所有满足面积正好7.52㎡的病害的明细全部调出来 → 返回了500条各种面积的
```

### 问题
- R3用户明确说"面积正好7.52㎡"，但结果里各种面积都有
- **过滤条件丢了！** 上下文补全的时候把"面积=7.52"这个条件丢了
- 而且R3用户说"所有...病害"，应该去掉"泛油"的过滤，但系统还是带着泛油

---

## Bug 4：纠正条件不生效

### 现象
```
R3：把西乡段所有满足面积正好7.52㎡的病害的明细全部调出来 → 返回了500条各种面积的
R4：我的意思是面积为7.52平方米的西乡段的病害明细，不是所有的 → 还是返回了500条
```

### 问题
- 用户明确纠正了："我的意思是面积为7.52㎡，不是所有的"
- 但系统还是返回了500条，纠正条件根本没生效
- 说明上下文补全的时候，没理解用户在纠正什么

---

## 根因分析

### 根因1：上下文补全不知道"什么时候该继承、什么时候该替换、什么时候该加新条件"

现在的补全是：
- 规则判断：是不是追问？是不是纠正？
- 是追问 → 继承所有旧条件
- 是纠正 → 替换条件
- 否则 → 新话题

**问题：判断太粗了，不知道：**
- 用户说"把明细调出来" → 应该继承所有旧条件（路线、时间、面积、病害类型），只换输出形式（从计数→明细）
- 用户说"所有...病害" → 应该去掉"泛油"的过滤，加"面积=7.52"的过滤
- 用户说"GPS轨迹也一起看" → 应该继承所有过滤条件，只换查询对象

### 根因2：纠正条件不生效

用户说"我的意思是...不是..."，这是在纠正之前的理解。
但系统不知道用户在纠正什么，只是机械地把新句子拼上去。

### 根因3：拆分器乱拆

"GPS轨迹也一起看？" → 不该拆成两个子问题。
应该是：继承所有过滤条件，只换查询对象。

---

## 整改方案

### 1. 上下文补全要更细地判断"操作类型"

现在的操作类型太少了，加几种：

| 操作类型 | 特征词 | 做法 |
|---------|--------|------|
| 换输出形式 | 把明细调出来、列出来、看看 | 继承所有过滤条件，只换输出形式（计数→明细） |
| 换查询对象 | GPS轨迹也一起看、照片呢 | 继承所有过滤条件，只换查询对象 |
| 加过滤条件 | 其中XX的、里面XX的 | 继承所有旧条件，加新过滤 |
| 替换过滤条件 | 不是所有的、我的意思是 | 把对应的旧条件换成新的 |
| 去掉过滤条件 | 所有病害、不限类型 | 去掉对应的过滤条件 |

**关键：要判断用户这句话是在"继承、替换、加新、去掉"哪种操作。**

### 2. 纠正条件要真正生效

用户说"我的意思是...不是..."，要：
1. 识别出用户在纠正哪个条件
2. 把那个旧条件换成新的
3. 其他条件继承

### 3. 拆分器不要乱拆

"GPS轨迹也一起看？"这种短追问，不该拆成两个子问题。
应该是：继承所有过滤条件，只换查询对象。

---

## 为什么现在长对话这么蠢？

**因为现在的补全是"机械拼接"：**
- 是追问就把旧条件全加上
- 是纠正就把新句子拼上去
- 不知道用户具体在改哪个条件

**真正智能的补全应该是：**
1. 先拆上一轮的所有条件
2. 再看用户这句话：是要加哪个？换哪个？去哪个？
3. 然后重新拼完整的问题

这就是你和我对话很流畅，但系统很蠢的原因——你是真理解，系统是在拼字符串。
