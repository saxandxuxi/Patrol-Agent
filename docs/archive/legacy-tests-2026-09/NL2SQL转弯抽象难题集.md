# NL2SQL 转弯+抽象难题集

> 不是直接查数字，是要**绕个弯、做个判断、综合一下**才能答的。
> 都是有数据的，不会出现"数据不足"。

---

## 测试重点观察

**这些题不是查数字，是做判断：**
- 养护优先级 → 要综合数量+密度+面积
- 趋势判断 → 要按时间排序看变化
- 严重程度 → 要综合多个维度
- AI可信度 → 要看置信度分布
- 分布特点 → 要看集中还是分散
- 巡检质量 → 要看巡检频率和数据
- 新旧程度 → 要按时间分两段
- 类型分布 → 要看集中度

**系统容易翻车的点：**
1. 直接返回一个数字，不下结论
2. 只看一个维度，不综合
3. 数据不足就硬编
4. 不理解抽象词（严重吗/靠谱吗/够不够）
