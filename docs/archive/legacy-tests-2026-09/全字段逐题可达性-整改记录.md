## 二、已验证（不需要 LLM 的部分）

- `named_columns`：隧道标签号/土建评定单位/监理单位名称、桥梁图片、边坡图片、定距采集画框位置、路段起终点坐标距离、路线公路里程、桩点经度 —— 全部落到真实列。
- 分库：`倾斜监测点里的接收时间` → postgresql；`GPS轨迹数据有多少条` → postgresql；`西乡段泛油有多少处` → mysql。
- 编译反馈：`basic_facilities_slope.memo` → 提示返回 31 个真实列；PG 项目拿到 disease → 返回"只能用 gps_point、inclination_point"。
- del_flag 自动补：`SELECT problem_type, enable_type FROM ai_problem_base` → 自动变成 `... WHERE del_flag = 0 LIMIT 500`；JOIN 查询仍然要求显式写 del_flag。
- 里程列：`route.distance` / `section.distance` 已回到 MDL（599 列），注释带"不准"警告。
- 抽样 46 题（报告里的失败题，LLM 可用时）：修好 25 → 33 → 32（同一批题三次结果有 LLM 波动，稳定收益在 +7~8 题）。
