#### 简单题
**题目：** 宝安大道西乡段一共有多少处病害？
**答案：** 911处
**SQL逻辑：** SELECT COUNT(*) FROM ai_problem p JOIN basic_facilities_routes r ON p.routes_id=r.id WHERE p.del_flag=0 AND r.del_flag=0 AND r.id='1b0b4a9f700477b1d96119caac87c168'

---

**题目：** 宝安大道西乡段上行和下行各有多少处病害？
**答案：** 上行911处，下行0处（当前数据全部上行）

```sql

FROM ai_problem p JOIN basic_facilities_routes r ON p.routes_id=r.id
WHERE p.del_flag=0 AND r.del_flag=0 AND r.id='1b0b4a9f700477b1d96119caac87c168'

```

### 5.3 多维度分组 + 解释

**题目：** 宝安大道西乡段各病害类型的数量占比和面积占比分别是多少？为什么数量最多的类型面积不是最大的？
**答案：** 泛油312处（占数量81.0%），总面积192.58㎡（占面积0.35%）；未识别73处（占数量19.0%），总面积55163.54㎡（占面积99.7%）。原因：未识别病害虽处数少但单处面积远大于泛油。
**SQL逻辑:**
```sql
SELECT COALESCE(b.problem_type, '未识别') AS 病害类型,
       COUNT(*) AS 数量,
       ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER(), 2) AS 数量占比,
       ROUND(SUM(COALESCE(p.area, 0)), 2) AS 总面积,
       ROUND(SUM(COALESCE(p.area, 0)) * 100.0 / SUM(SUM(COALESCE(p.area, 0))) OVER(), 2) AS 面积占比
FROM ai_problem p
JOIN basic_facilities_routes r ON p.routes_id=r.id
LEFT JOIN ai_problem_base b ON p.damage_type=b.problem_code
WHERE p.del_flag=0 AND r.del_flag=0
  AND r.id='1b0b4a9f700477b1d96119caac87c168'
GROUP BY b.problem_type
ORDER BY 数量 DESC
```
