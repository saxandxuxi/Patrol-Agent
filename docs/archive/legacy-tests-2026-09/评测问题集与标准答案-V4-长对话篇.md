## 一、长对话（LD1-LD10）——多轮语义验收

> **长对话通用验收规则**：① 每轮必须独立答对，且**上一轮的条件/口径要能被下一轮继承或替换**（语义 JSON 方案下=复制上轮 JSON 改字段，禁止字符串拼接式继承）；② 轮间出现"那/呢/它/纠正/错了"等指代时必须正确消解；③ 答案数字全部来自 SQL（不能从问题抄、不能编）；④ 轮次间切换意图（data→knowledge→composite）不得串扰。

## 二、比例系列（RAT1-RAT6）—— shape=ratio 语义验收

> **专用验收规则**：每题必须输出**百分比**（含分子/分母，如"936/1702 ≈ 55.0%"）；**不得输出"多少处"替代比例**；分子/分母必须由 SQL 算出。本系列是语义 JSON `shape=ratio` 的验收题，禁止用"关键词→distribution"旧链路硬答。

### RAT1【★★★★】全库病害里泛油占多少比例？
- **标准答案**：**936/1702 ≈ 55.0%**
- **校验点**：必须 55.0%（不是"泛油 936 处"）

### RAT2【★★★★】西乡段病害里泛油占多少？
- **标准答案**：**534/911 ≈ 58.6%**
- **校验点**：58.6%（与 RAT1 区分，路线口径）

### RAT3【★★★★】恒明珠病害里泛油占多少？
- **标准答案**：**402/749 ≈ 53.7%**
- **校验点**：53.7%

### RAT4【★★★★★】全库泛油里 7月占多少比例？
- **标准答案**：**793/936 ≈ 84.7%**（7月泛油 793 = 西乡 534 + 恒明珠 259；6月仅 143）
- **校验点**：分子=7月泛油、分母=全库泛油；84.7%

### RAT5【★★★★★】西乡段 7月30日泛油占 7月泛油多少比例？
- **标准答案**：**185/534 ≈ 34.6%**（185 为 7/30 单日，534 为西乡段 7 月全月）
- **校验点**：34.6%（不是 185/401、不是 185/911）

### RAT6【★★★★】全库病害里置信度≥0.7 的占多少？
- **标准答案**：**893/1702 ≈ 52.5%**（893=全库病害置信度≥0.7，V3 基线已复算）
- **校验点**：52.5%

## 四、泛化验收题（G 系列）—— 语义中间层专用

> **用途**：这 10 道题**不在 V3 任何模板词表里**（换了问法、换了表达），专门验收"语义类别驱动"是否真正替代"关键词模板"。
> **判定**：语义 JSON 方案下应全部答对；模板补丁式修法必然有题答错（这就是治本/治标的判据）。

- **G1【★★★★★】泛油比裂缝多多少处？** → 泛油 **936 处**，裂缝 **0 处**（库中无裂缝类数据，如实说明），**多 936 处**
- **G2【★★★★★】7月泛油比6月多了百分之多少？** → (793−143)/143 ≈ **+454.5%**
- **G3【★★★★★】西乡段 K0+800 到 K0+900 的泛油占西乡段泛油多少比例？** → 81/534 ≈ **15.2%**（该区间 81 处 / 92.06㎡）
- **G4【★★★★★】置信度在0.5到0.7之间的泛油有多少处？** → **332 处**（全库）
- **G5【★★★★★】泛油中面积超过5㎡且置信度不低于0.7的有多少？** → **17 处**（面积=7.52 的 17 条全部满足）
- **G6【★★★★】西乡段泛油按天看哪天最多？** → **7月29日（216 处）**（7/30=185、7/21=60、7/22=59、7/15=14）
- **G7【★★★★】恒明珠和西乡段，哪边泛油平均面积大？** → **西乡段 1.0670㎡ > 恒明珠 0.9352㎡**（对比结论，不是罗列）
