# NL2SQL 抽象测试题集（单轮 + 长对话）

> 都是绕弯的、不直接问字段的抽象问题。
> 你拿去测，看系统能不能理解这些"人话"。

---

## 一、单轮抽象难题（15道）

### 评价判断类（问"好不好/严不严重"）

1. **养护资源应该优先投哪条路？为什么？**
   → 考：会不会综合多个指标（数量、密度、面积）下结论？

2. **西乡段的病害情况算严重吗？**
   → 考：会不会先查数据，再判断"严重"的标准？

3. **AI识别的结果靠谱吗？有多少需要人工复核？**
   → 考：会不会理解"靠谱/复核"对应置信度分层？

4. **恒明珠段的病害是老问题多还是新问题多？**
   → 考：会不会理解"老问题/新问题"对应时间分布？

---

### 趋势变化类（问"越来越多/越来越少"）

5. **最近巡检发现的病害数量，是在增加还是在减少？**
   → 考：数据不足时会不会如实说？会不会硬编？

6. **西乡段的病害面积，最近是不是越来越大了？**
   → 考：会不会理解"越来越大"是时间趋势？

7. **泛油病害在这条路上，是越发展越多还是越发展越少？**
   → 考：会不会理解"发展"是时间维度？

---

### 对比比较类（问"哪个更好/哪个更严重"）

8. **西乡段和恒明珠，哪个的养护压力更大？从哪几个方面看出来的？**
   → 考：会不会多维度对比？会不会每个维度都算出来？

9. **哪条路的病害最"分散"？哪条路最"集中"？**
   → 考：会不会理解"分散/集中"对应病害密度？

10. **两条路比起来，哪条路的"质量"更好？**
    → 考：会不会理解"质量"是综合判断？

---

### 资源效率类（问"够不够/大不大"）

11. **现在的巡检频率够不够？哪条路巡得更勤？**
    → 考：会不会算单位里程的巡检次数？

12. **如果要在一个月内把所有病害都处理完，工作量大不大？**
    → 考：会不会理解"工作量大不大"是假设性计算？

13. **西乡段的病害密度，在全国算什么水平？**
    → 考：数据不足时会不会如实说？

---

### 归因解释类（问"为什么"）

14. **为什么西乡段数量最多的病害类型，面积反而不是最大的？**
    → 考：会不会把数量和面积两个维度结合起来解释？

15. **为什么西乡段的病害这么集中在一段时间里？**
    → 考：会不会从时间、方向、类型三个维度解释？

## 二、长对话抽象难题（8组）

### 第1组：数量对比 + 占比计算

```
R1：西乡段泛油有多少处？
R2：恒明珠呢？
R3：哪个多？多多少？
R4：那泛油占各自总病害的百分之多少？
```

**考什么：**
- R2：换主体，继承病害类型
- R3：比较差值，要把前两轮数字带进来
- R4：换指标（数量→占比），继承两个主体

---

### 第2组：Top结果追问

```
R1：全库置信度最高的病害是哪条？
R2：它是什么类型的？
R3：这种类型的病害，全库一共有多少处？
R4：占全部病害的百分之多少？
```

**考什么：**
- R2：指代Top结果，不要补成新过滤条件
- R3：换主体，继承病害类型
- R4：换指标（数量→占比）

---

### 第3组：面积相关追问

```
R1：西乡段的病害平均面积是多大？
R2：最大的有多大？
R3：最大的那条是什么类型的？
R4：这种类型的平均面积是多少？
```

**考什么：**
- R2：换指标（平均→最大）
- R3：指代Top结果
- R4：换主体，继承路线

---

### 第4组：病害类型分布追问

```
R1：恒明珠段的病害类型分布怎么样？
R2：哪一类最多？
R3：那类占比多少？
R4：比西乡段的同类占比高还是低？
```

**考什么：**
- R2：从分布里找最多的
- R3：换指标（数量→占比）
- R4：对比两条路

---

### 第5组：密度/间距追问

```
R1：西乡段的病害密度是多少？
R2：恒明珠呢？
R3：哪个密度更高？高多少？
R4：那平均每隔多少米出现一处？
```

**考什么：**
- R1：转弯计算（数量÷长度）
- R2：换主体
- R3：比较差值
- R4：换指标（密度→间距）

---

### 第6组：过滤条件叠加

```
R1：西乡段有多少处泛油？
R2：面积大于10平方米的有多少？
R3：其中置信度低于0.7的有多少？
R4：占全部泛油的百分之多少？
```

**考什么：**
- R2：加过滤条件（面积>10）
- R3：再加过滤条件（置信度<0.7）
- R4：换指标（数量→占比）

---

### 第7组：追问剩下的/其他的

```
R1：西乡段面积大于5平方米的病害有多少处？
R2：其中泛油占多少？
R3：那剩下的都是什么类型的？
R4：各有多少处？
```

**考什么：**
- R3："剩下的"指代除了泛油之外的
- R4：分组统计

---

### 第8组：纠正 + 重算

```
R1：西乡段泛油有多少处？
R2：错了，我说的是全部病害
R3：那平均面积是多少？
R4：恒明珠的平均面积比西乡段高还是低？
```

**考什么：**
- R2：纠正条件（去掉病害类型过滤）
- R3：换指标
- R4：对比两条路

## 三、测试时重点观察什么

1. **抽象词能不能理解？**
   - "严重吗？" → 系统会不会真的去判断
   - "靠谱吗？" → 系统会不会联想到置信度
   - "分散/集中" → 系统会不会联想到密度

2. **长对话指代能不能补全？**
   - "那恒明珠呢？" → 会不会继承其他条件
   - "它是什么类型的？" → 会不会指代Top结果
   - "剩下的呢？" → 会不会理解是除了XX之外的

3. **转弯计算能不能做？**
   - "密度" → 数量÷长度
   - "占比" → 部分÷总数
   - "平均间距" → 总长度÷数量

4. **数据不足时会不会硬编？**
   - 只有一个月的数据，问"趋势" → 会不会说"数据不足"
   - 没有全国数据，问"全国算什么水平" → 会不会如实说

## 出题思路说明

这些题的特点：
- **不直接问字段名**：不说"pile_distance"、"confidence"，说"桩号"、"置信度"
- **问法很口语化**：像真人说话，不像写SQL的人
- **需要推理**：不是直接查COUNT(*)，要算、要比、要判断
- **有陷阱**：问"趋势"但只有一个月数据，测系统会不会硬编
