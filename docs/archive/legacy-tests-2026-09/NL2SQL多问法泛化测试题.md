# NL2SQL 多问法泛化测试题

> 同一个业务场景，换各种问法。
> 都是有数据的，不会出现"数据不足"。
> 你拿去测，看系统不管怎么问都能答对不。

## 测试方法

**每个场景10种问法，看系统能不能都答对：**
- 如果10种问法都答对 → 泛化能力强 ✅
- 如果只有2-3种问法答对 → 还是穷举模板 ❌
- 如果换个说法就不对 → 还是"记模板"，不是"真理解"

**重点观察：**
- 同义词能不能理解？（泛油/裂缝/病害类型）
- 语序变了能不能理解？（"有多少处"和"多少条"）
- 口语化能不能理解？（"拿不准的"、"大病害"）
- 省略成分能不能理解？（"呢"、"呢？"、"那呢"）
