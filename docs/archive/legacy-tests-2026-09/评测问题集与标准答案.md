## 二、对比分析类（答案互不相同）

### C1【★★★】宝安中心--恒明珠 6月和7月的泛油，哪个月多？多多少？
- **期望**：**7月多**：7月 **259** 处 vs 6月 **143** 处，**多 116 处**

```sql
SELECT DATE_FORMAT(p.collection_time, '%Y-%m') AS month, COUNT(*) AS cnt
FROM ai_problem p

```

### C3【★★★★】宝安大道西乡段和宝安中心--恒明珠，哪条路的泛油平均面积更大？
- **期望**：**西乡段 1.0670㎡ > 恒明珠 0.9352㎡**

```sql
GROUP BY r.id, r.short_name;
```

### C4【★★★★】宝安大道西乡段前 500 米（K0+000~K0+500）和后 500 米（K0+500~K1+000）哪段泛油多？

```sql
  SUM(JSON_UNQUOTE(JSON_EXTRACT(pic_position, '$.confidence')) >= 0.7) AS high_conf,
```

```sql
SELECT COUNT(*) AS cnt
```

### F1【★★★★★】全库泛油的平均面积是多少？面积超过这个平均值的泛油有多少条？
- **期望**：全库泛油均值 **1.0104㎡**（936 条）；面积 > 均值的泛油 **206 条**
- **校验点**：子查询（`WHERE area > (SELECT AVG(area) ...)`）；注意与西乡段均值 1.0670、恒明珠 0.9352 区分——题目问全库
- **标准 SQL**：
```sql
SELECT ROUND(AVG(area), 4) AS avg_area, COUNT(*) AS cnt
FROM ai_problem WHERE del_flag = 0 AND damage_type = '10';

SELECT COUNT(*) AS cnt
FROM ai_problem WHERE del_flag = 0 AND damage_type = '10'
  AND area > (SELECT AVG(area) FROM ai_problem WHERE del_flag = 0 AND damage_type = '10');
```

### F2【★★★★★】全库面积最大的泛油病害有几条并列？各在哪条路？

- **标准 SQL**：

### F8【★★★★】6月和7月平均每天各发现多少条病害？
- **期望**：**6月约 53.8 条/天、7月约 197 条/天**（7 月约为 6 月的 3.7 倍）
- **校验点**：月计数 ÷ 当月有数据的天数（COUNT(DISTINCT DAY(...))），不是 ÷30/31；能看出 7 月采集强度陡增
- **标准 SQL**：
```sql

       COUNT(*) / COUNT(DISTINCT DAY(collection_time)) AS avg_per_day
FROM ai_problem WHERE del_flag = 0 GROUP BY m;
```

### F9【★★★★★】"未知路线"那 42 条病害，覆盖什么时间范围？有什么共同特征？

- **校验点**：多字段联合归纳（时间 MIN/MAX + 类型 + 方向），是数据质量归因题
- **标准 SQL**：
```sql

       COUNT(DISTINCT damage_type) AS types, SUM(up_or_down <> '') AS has_dir
FROM ai_problem p JOIN basic_facilities_routes r ON p.routes_id = r.id
WHERE p.del_flag = 0 AND r.short_name NOT IN ('宝安大道西乡段','宝安中心--恒明珠');
```

### F10【★★★★】西乡段 7月29日和7月30日两天的泛油，合计占 7 月总数的多少比例？

```sql
        AND p.collection_time >= '2026-07-01' AND p.collection_time < '2026-08-01') t;
```
