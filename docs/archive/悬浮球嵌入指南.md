# 悬浮球嵌入指南（把智能体接进亿维业务平台）

> 前提说明：`docs/reference/亿维道路AI巡检_HTTP_V2.pdf` 是**数据推送协议**
> （亿维数据平台 → 业务平台：`/monitor/oauth2/token`、`/monitor/data/gps`、`/monitor/data/report`），
> 不是宿主页面的 UI 接口。所以"嵌入"按宿主页面 + iframe 做，**鉴权风格对齐它的 token 头**。

---

## 一、宿主页面要做的（3 步）

### 1. 画一个悬浮球，点开是个 iframe

```html
<!-- 放在巡检平台页面模板最底部（只加这一段，不动后端） -->
<div id="road-copilot"></div>
<script>
  const COPILOT_BASE = 'http://<智能体地址>:18730'
  // token 由宿主登录态拿（见第三节），没有就留空
  const COPILOT_TOKEN = window.currentUserToken || ''

  const root = document.getElementById('road-copilot')
  root.innerHTML = `
    <div id="rc-ball" style="position:fixed;right:24px;bottom:24px;width:56px;height:56px;
         border-radius:50%;background:#2b6cf6;color:#fff;display:flex;align-items:center;
         justify-content:center;cursor:pointer;box-shadow:0 6px 20px rgba(0,0,0,.25);z-index:9999">
      巡检助手
    </div>
    <div id="rc-panel" style="display:none;position:fixed;right:24px;bottom:92px;width:420px;
         height:600px;border-radius:12px;overflow:hidden;box-shadow:0 12px 40px rgba(0,0,0,.3);z-index:9999">
      <iframe id="rc-frame" style="width:100%;height:100%;border:0"
              src="${COPILOT_BASE}/?mode=widget&token=${encodeURIComponent(COPILOT_TOKEN)}"></iframe>
    </div>`
  document.getElementById('rc-ball').onclick = () => {
    const panel = document.getElementById('rc-panel')
    panel.style.display = panel.style.display === 'none' ? 'block' : 'none'
  }
</script>
```

`?mode=widget` 会隐藏顶部导航和知识库/数据库/模型设置，只渲染对话面板；
面板右上角有「打开完整工作台 ↗」，需要重功能时新窗口打开完整页面。

### 2. 把宿主域名加进 CORS

`backend/.env`：

```
CORS_ALLOW_ORIGINS=http://巡检平台域名,http://localhost:5173
```

（现在默认 `*`，内网调试可以直接用；正式接入建议写明确来源。）

### 3. 需要鉴权就配 token

`backend/.env`：

```
WIDGET_TOKEN=<和宿主约定的一串口令>
# 也可以给多个宿主/环境各发一个，逗号分隔：WIDGET_TOKEN=tok-hostA,tok-hostB
```

配了之后 `/api/chat`、`/api/preset-query`、`/api/feedback/report` 会要求请求头
`token: <值>`（对齐亿维协议的 `token: ${clientToken}` 风格），**也接受 URL 参数 `?token=`**。
两种透传方式：

- **URL 参数**（上面示例）：iframe 地址带 `&token=xxx`，前端调用时自动放进请求头
- **postMessage**（宿主不想把 token 放 URL 时）：宿主 `iframe.contentWindow.postMessage({type:'copilot-token', token}, COPILOT_BASE)`，
  智能体侧接收后存入内存再用

> 内网互信环境下也可以把 `WIDGET_TOKEN` 留空，先跑通体验，鉴权方案确定后再开。

## 二、悬浮球里能做什么（已经做好）

| 能力 | 说明 |
|---|---|
| 自然语言问答 | 走语义层（Wren），复杂问题执行前先「大白话复述确认」 |
| 预置问题一键查 | 顶部下拉，8 条验证过的固定统计，毫秒级、不走 LLM |
| 口径卡片 | 每个回答附「范围/对象/排除/数据截至」+ 异常提醒 |
| 答对/答错反馈 | 攒 bad case（`/api/feedback/report`） |
| 结果明细 | 「查看这次结果」→ 右侧表格（桩号/类型/面积/时间/图片） |

不放（留给完整工作台）：知识库管理、数据库/Schema 浏览、模型设置、批量导出。

## 三、数据侧对应关系（读数据时用得上，来自同一份协议）

| 协议字段 | 含义 | 我们库里的对应 |
|---|---|---|
| `deviceCode` | 设备唯一编号 | `ai_problem.device_code` |
| `dataType=disease` | 病害数据 | `ai_problem` |
| `dataType=asset` | 资产数据 | `ai_asset_main` |
| `dataType=distance` | 定距采集 | `ai_distance_capture` |
| `lng` / `lat` | WGS-84 经纬度 | `ai_problem.lng` / `ai_problem.lat`（同一坐标系） |
| 采集时间格式 `yyyy-MM-dd HH:mm:ss:SSS`  | 病害采集时间 | `ai_problem.collection_time`（timestamp(3)） |
| 心跳周期 7 秒、心跳时间 `yyyy-MM-dd HH:mm:ss` | 设备在线情况 | 目前库里没有心跳表，需要时再建 |

协议里"业务平台提供鉴权/心跳/采集三个端点"指的是**接收方**（业务平台）。
本智能体是**读这份数据的人**，所以不需要实现这些端点；但字段口径沿用同一套，避免两边对不上。

## 四、上线检查清单

- [ ] 智能体后端在宿主能访问的地址上启动（`python run.py`，默认 18730）
- [ ] 宿主域名加进 `CORS_ALLOW_ORIGINS`
- [ ] 需要鉴权就配 `WIDGET_TOKEN`，并把 token 透传进 iframe
- [ ] 访问 `http://<智能体地址>/?mode=widget` 确认只显示对话面板
- [ ] 点右上角「打开完整工作台 ↗」能正常打开完整页面
- [ ] 用一条预置问题（如"各路线病害密度排名"）验证数据返回
